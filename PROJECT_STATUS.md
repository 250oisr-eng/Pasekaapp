## 6. Нерешённые ошибки, риски и ограничения

1. Полный backup/restore round-trip для `equipmentInventory.items` и footprint решёток не проверен.
2. UI назначения/установки решёток в физические корпуса и полный конфигуратор секций отсутствуют.
3. Профиль `sectional-multiqueen-v1` не активирован; OP-07 нельзя считать доступной для завершения обычным пользовательским сценарием.
4. Не принято доменное решение: одна исходная семья/колония с тремя секциями и тремя матками либо три самостоятельные семьи с общей историей происхождения. Это решение требуется до связывания секций с реестрами семей и маток.
5. Точная физическая схема четырёх медовых корпусов не подтверждена; не кодировать её по догадке.
6. PR #90 и #91 содержат пересекающиеся изменения документов управления; GitHub ранее сообщал о конфликте/непригодности независимого слияния PR #90. Перед слиянием нужна консолидация без потери протокола DOCX.
7. PR #94 дублирует часть проверки PR #95; не объединять оба независимо без анализа зависимости и diff.
8. Workers Builds ранее завершался failure без поясняющих аннотаций на более раннем этапе реестра; причина не установлена. Не заявлять deployment.
