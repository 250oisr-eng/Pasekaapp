# Пасека — PWA

Мобильный журнал пчеловода. Сейчас реализованы динамический список ульев, семьи с выбором породы, журнал записей, локальное хранение IndexedDB, внутренние снимки и ручной JSON backup/restore.

## Публикация
GitHub → Settings → Pages → Deploy from a branch → Branch: main → Folder: /(root) → Save.

После публикации откройте HTTPS-адрес на Android в Chrome и выберите «Установить приложение» или «Добавить на главный экран».

## Важно
Данные хранятся в браузере устройства. Экспортируйте архив и храните его отдельно. Не очищайте данные браузера без резервной копии. В коде предусмотрена интеграция защищённого входа через Neon Auth и запросов к Cloudflare Workers AI. Фактическая работа ИИ зависит от отдельного развёртывания Cloudflare Worker, привязки Workers AI и настроек Neon Auth. Коммит в GitHub и публикация GitHub Pages сами по себе не обновляют Worker. Worker принимает запросы с GitHub Pages и Android Capacitor (`https://localhost`).
