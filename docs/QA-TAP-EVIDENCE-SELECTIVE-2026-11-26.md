Текущий `main` использует `npm test` и `quality.yml` без анализа пропусков. Исправление ограничено синтетическим отчётом уже существующего полного прогона.

**F3.** Новый `scripts/qa-tap-evidence.mjs` локально читает только явно указанный файл ограниченного размера (не более 16 MiB, обычный несимвольный файл); проверяет завершённый TAP v13 с одной непротиворечивой сводкой `tests/pass/fail/cancelled/skipped/todo`. Статус `PASS_SYNTHETIC` возможен только при ненулевом полном наборе без failures, cancelled, skipped и todo. Неполные, повреждённые, дублирующиеся или недопустимые сводки — `NOT_VERIFIED`; частично выполненные тесты — `PARTIAL`. CLI завершает работу с ненулевым кодом для любого статуса кроме `PASS_SYNTHETIC`, не публикует содержимое лога. `quality.yml` единожды выполняет прежний `npm test`, временно сохраняет stdout/stderr в `RUNNER_TEMP` (вне репозитория и без upload) и сохраняет исходные коды возврата npm и tee.

**F4.** Нет вызовов GitHub API, токенов, облачных моделей, записи в production, изменений пользовательских данных, миграций/видео, доступа к устройству. Старые `qa/tracked-drafts.json`, статические списки PR, полные матрицы тестов и дополнительные сетевые пробы из #532 **не переносим**. Статус `PASS_SYNTHETIC` означает исключительно полноту синтетического CI Node, не Android binary, OnePlus, backup/restore, видео или релиз.

**F5–F7.** Негативные тесты на FAIL/PARTIAL, missing/duplicate, inconsistent counts, unsafe-number, symlink/dir/empty/oversized и неизменность источника.
