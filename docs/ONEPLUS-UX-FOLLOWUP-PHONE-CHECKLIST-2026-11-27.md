1. Главная: нажать каждый из четырёх счётчиков; при пустом списке — корректное пустое состояние, после создания искусственных записей — соответствующие семьи/ульи и переходы. 
2. Переключить «Зимовка», «Весна-лето», «Осень»; состав сезонных быстрых пунктов меняется, постоянные разделы доступны. 
3. Вертикально открыть создание улья, ввести примечание при открытой клавиатуре. Нажать подтверждение без её ручного закрытия. Проверить создание единственного улья. 
4. Убедиться, что после сохранения предлагаются варианты семьи. Выбрать «Готовая семья», проверить происхождение, сохранить; второй раз выбрать другой вариант. При отмене нет новой семьи. Перейти к настройке. 
5. В технической настройке открыть рамку. Вощина/полоска — только «Вощина»; сушь — все 10 остальных статусов. Переключение типа обновляет список, запрещённого статуса нет. Не менять реальный инвентарь.
6. В учебной записи фото/видео имеют одинаковую форму и размер, значки без видимого текста. Не снимать реальные видео, не подключать аккаунты. 
7. TalkBack (если возможно): доступные подписи и возвращение из форм; рабочий APK и старые QA не изменены по наблюдению.
