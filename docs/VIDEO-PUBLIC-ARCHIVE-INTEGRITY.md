# Безопасная проверка вручную полученного общественного ZIP-датасета

Дата: 2026-11-20. Статус: отдельная офлайн-утилита, **не** автоматическое разрешение лицензии/обучения.

## Проверка доступности Mendeley

Официальная документация Digital Commons Data API: https://data.mendeley.com/api/docs/ . Для public dataset metadata имеется `GET /datasets/{id}?version=6`, для списка файлов `GET /datasets/{id}/files?version=6`, zip metadata `GET /datasets/{id}/zip?version=6` (набор ID `8gb9r2yhfc`). В текущей среде попытка прямого запроса `https://api.data.mendeley.com/datasets/8gb9r2yhfc?version=6` завершилась сетевой ошибкой DNS; веб-инструмент также не получил JSON API. **Никаких фактических ZIP-файлов не скачано и не открыто; фактическая лицензия содержимого архива не проверена.**

## Офлайн-инспектор

`tools/inspect_bee_archive.py` на стандартной библиотеке Python. Предназначен только для **уже самостоятельно полученного публичного ZIP**, без загрузки из сети или контакта с пользовательскими исходниками. Команда:

```bash
python3 tools/inspect_bee_archive.py ./public_bees_v6.zip
```

Выдаёт JSON в стандартный вывод со SHA-256 всего архива и каждого файла, размерами и перечнем возможных licence/README/COPYING/NOTICE/attribution файлов. Сканирует содержимое в памяти порциями без распаковки на диск.

### Fail-closed защиты

- Отклоняются архивы с небезопасными относительными/абсолютными именами, попытками `../`, пути с обратным слешем и Windows-drive, повторы имён без учёта регистра, символьные ссылки, шифрованные файлы, неподдерживаемое сжатие, повреждённые записи.
- Ограничения: максимум 10 000 entries, 512 MiB на файл, 2 GiB суммарно в несжатом виде, ограничение большого коэффициента сжатия, проверка фактического числа разжатых байтов. **Сверх этих лимитов архив отклоняется, а не подвергается небезопасному извлечению.**
- Нет `extractall`, внешних API, загрузки, изменения архивов, перезаписи файлов, пользовательских видео или локальной базы. Не удаляет ни архив, ни пользовательские данные.
- Только имена licence-документов обнаруживаются; **тексты не проверяются автоматически**. Успешный JSON всегда содержит `licenseVerified=false`, `trainingAuthorized=false`, `modelApproved=false`, `recognitionSucceeded=false`, `cleanupAuthorized=false`.
- Атакующий теоретически может создать корректный ZIP с ложным LICENSE. Факт наличия документа и совпадения хеша не является юридическим разрешением.

### Проверки

`tests/test_inspect_bee_archive.py` — 6 проверок (успех inventory, traversal, дубли, symlink, zip bomb, malformed archive). `tests/public-archive-inspection.test.mjs` запускает Python suite через существующий `npm test` в CI. Локальный изолированный Python suite выполнен 6/6.

### До реального обучения

1. Получить данные из подтверждённого официального источника, зафиксировать metadata/DOI/версию, размер и SHA-256 скачанного архива (сверить со значением Mendeley, если доступно).
2. Проверить реальные лицензии архивных файлов, авторство, требования CC BY 4.0 к атрибуции, отсутствие дополнительных ограничений, происхождение изображений/annotations. Не путать лицензию статьи CC BY-NC-ND и карточки датасета.
3. Определить истинные исходные video ID, session/day/hive; только затем разделить train/validation/test и создать manifest с реальными хешами.
4. Провести первый законный training-from-scratch без checkpoint с непроверенными правами; отдельно оценить inference/quality/ONNX/Android и video cleanup safety.
