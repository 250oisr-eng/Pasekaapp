# Протокол измерений на физическом Android (2026-11-20)

Этап: **схема неподтверждённого отчёта**. Ни одного физического Android inference этот PR не выполняет.

`js/android-inference-evidence.js` принимает отчёт только с явным `physical_android_inference`, on-device `wasm_cpu`, Android/System WebView version, model ID/version/SHA-256, маркированным тестовым датасетом ID/SHA-256, фактом теста с отключённой сетью и offline reload, измерениями времени с cold start, ground truth (TP/FP/FN).

Результат всегда `physicalTestVerified=false`: данные отчёта самодекларированы, подделываемы и **не подтверждают** физический эксперимент. Метрики precision и recall рассчитываются как диагностические, не являются окончательной независимой проверкой или автоматическим подтверждением точности. Пустые детекции допускаются как отрицательный результат и не означают успешное распознавание.

Нет реального ONNX session, загрузки весов, кадров, действий с IndexedDB, сети, Android/Gallery/MediaStore и удаления оригиналов. Для будущего реального испытания отдельно нужны видео с независимой разметкой, лог модели, измерения устройства, проверки повторяемости и оценка ошибок направления. Всё это — задача после юридического допуска конкретных весов.

Источники: https://onnxruntime.ai/docs/tutorials/web/performance-diagnosis.html ; docs/VIDEO-ANDROID-INFERENCE-EVIDENCE-GATES.md.
