## База и границы измерений

- Основной репозиторий `250oisr-eng/Pasekaapp`, main `8144ec8fe7e61c2f70f067c78f299bf0e7551dd7`. Исходная ветка P2: Draft #423, `5da0522a116ffae27681fd1c81590421b8cf4fe3`: Fast Quality #45082087989 **1222/1222** PASS, Android Debug #45082087992 success. Успех родителя не подтверждает новый код P2.
- Дерево Git для исходной рабочей ветки: `index.html` **604 815 байт**, `js/` **596 340 байт** в 38 файлах. Это **не** измерение gzip-передачи, APK, RAM или времени открытия. Репозиторий не содержит `.onnx`, `.tflite`, `.wasm` бинарников; нельзя заявлять об ускорении детектора пчёл.
- Обнаруженный кодовый избыточный расчёт: `renderHiveDirectory` читал все frame arrays даже при пустом запросе; `renderJournalRecords` строил полный поисковый текст даже без строки; `renderHome` фильтровал весь список задач отдельно для каждого улья и вызывал `today()` повторно. Исправление этих фактов — предмет первого блока P2.
- `listEntranceVideos` использует `entrance_media.getAll()` и отдаёт записи с Blob при открытии списка, хотя превью отдельно вызывает `getEntranceVideo(id)`. Отдельный риск затрат памяти, **не исправлять без регрессий SHA/backup/стратегии старых IndexedDB**.
- Физическое устройство, профили производительности Android, энергопотребление, ограничение памяти на реальной пасеке и продакшен-съёмка недоступны; такие проверки имеют статус BLOCKED, а не PASS.

## Первый ограниченный блок: интерфейс без изменения данных

Branch: `perf/p2-render-hotpaths-2026-11-23`, parent #423.

- `index.html`: `renderHiveDirectory` пропускает чтение рамок без поисковой строки или при совпадении быстрых полей; сохраняет исходный поиск по frameId. `renderJournalRecords` проверяет структурные фильтры до преобразования медиа/строки поиска. `renderHome` группирует pending/suggested задачи один раз за рендер и использует единую дату.
- `tests/p2-render-hotpaths.test.mjs`: поведенческие проверки пустого поиска, фильтра сборки, поиска семьи/рамки, порядка фильтров журнала, одной итерации задач, единой даты и содержимого выдачи.
- Нет изменений схемы IndexedDB, `S`, истории, видео, Service Worker, Android permissions, сервера или моделей. Никакого автоматического удаления. Обратимость — чистый revert одного code PR.
- Выполнение P2.1 **не подтверждено**, пока Fast Quality и Android Debug не прошли на exact HEAD данного PR. Предмет P2 целиком **не может быть помечен READY** до независимых физических проверок и закрытия связанных рисков P0/P1.
