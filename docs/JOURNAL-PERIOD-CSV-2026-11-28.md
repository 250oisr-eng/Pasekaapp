# CSV-сводка журнала по всем ульям — F0–F7

Новая пользовательская функция: в раскрываемой сводке журнала за выбранный период доступна отдельная кнопка **Скачать сводку CSV**. Экспортируются сохранённые неархивные записи по ульям и типам: даты, имя/исторический ID улья, тип, количество и общий итог. Личные тексты, фото, видео, координаты и вложения не экспортируются. Используется стандартный CSV-escape проекта (BOM, `;`, CRLF, защита от формул). Исходная база не изменяется. Неправильный диапазон дат отклоняется. Пустые ульи представлены нулевыми строками; удалённые исторические ульи не подменяются текущими.

Тесты: `tests/journal-period-csv.test.mjs` — выбор периода, исключение архивных данных, отсутствие медиа, целостность исходного состояния, формулы, пустые ульи, повреждение данных и даты. Проверка на Android, Node, Chromium и Governance обязательна на итоговом SHA. OnePlus не проверялся; это выгрузка отчёта, не резервная копия.
