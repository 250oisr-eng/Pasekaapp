# Локальный браузерный тестировщик Windows 11

## Назначение

Изолированная проверка интерфейса приложения в Google Chrome. Используется для проверки всех 11 основных разделов и поиска горизонтального переполнения, обрезанного содержимого и элементов, выходящих за границы viewport.

## Запуск

Требуются Windows 11, Google Chrome и Node.js 20.10+ (рекомендуется Node.js 22 LTS).

В PowerShell из корня репозитория:

```powershell
node --version
npm run test:browser:local
```

Если Chrome установлен в нестандартной папке:

```powershell
$env:PASEKA_CHROME_PATH = 'C:\Путь\к\chrome.exe'
npm run test:browser:local
```

## Безопасность

- Chrome запускается с отдельным временным профилем.
- Обычный профиль пользователя и локальная база пасеки не открываются.
- Тестовый HTTP-сервер слушает только loopback.
- Все запросы страницы за пределы локального origin блокируются до отправки.
- Service Worker и его кеш обходятся, чтобы тестировать файлы текущей рабочей копии.
- Данные пользователя не читаются, не изменяются и не удаляются.

## Что проверяется

- Запуск приложения и наличие всех 11 основных вкладок.
- Переключение на каждую вкладку.
- Ширины viewport: 320, 360, 390, 768, 1024 и 1365 px.
- Горизонтальное переполнение документа.
- Элементы активной панели с scrollWidth больше clientWidth (кроме явно прокручиваемых областей).
- Элементы активной панели, чьи границы выходят за viewport.
- Необработанные JavaScript-исключения, console.error и локальные HTTP-ошибки.
- Снимки основных экранов и мобильного экрана «Медоносы».

Проверка диалогов, требующих выбранного реального улья или семьи, выполняется отдельно на изолированных тестовых фикстурах. Smoke-тест не создаёт фиктивные записи пасеки.

## Результаты

Отчёт JSON и снимки сохраняются в `.local-test-results/`. Каталог исключён из Git. GitHub Actions запускает аналогичную проверку на Windows runner при изменении UI/runtime-файлов.
