# Проверка пяти реальных Pascal VOC / JPEG пар из разных частей LILA ZIP

Дата: 2026-11-20. Статус: исследовательский тест, без внедрения AI и без пользовательских видео.

## Цель
Первый успешно проверенный JPG/XML `ML-Data/Chueried_HempBox_1` подтвердил базовый формат, но одного файла недостаточно для анализа разнообразия разметки и размеров. Новый read-only инструмент `tools/sample_lila_five_pairs.py` использует уже проверенные механизмы ZIP Range и выбирает **5 равномерно разнесённых индексов в отсортированном списке XML-файлов**. Это не случайная научная выборка, не независимые видео и не train/test split.

## Как устроена проверка
1. `HEAD`, ZIP EOCD, central directory — как в `sample_lila_voc_range.py`.
2. Детерминированные индексы: `0, floor((N-1)/4), floor(2(N-1)/4), floor(3(N-1)/4), N-1`.
3. Для каждого XML — читаются небольшие сжатые данные через HTTP `206 Partial Content`, проверяются ZIP CRC и XML размер/границы координат.
4. Для каждого XML ищется **строго одна** одноимённая JPG/JPEG запись. Имя из поля `filename` XML, если заполнено, должно совпадать с фактическим JPEG.
5. Файл JPEG извлекается только в оперативной памяти и в пределах 3 MiB, проверяется ZIP CRC, SHA-256, JPEG SOF размер, равенство с VOC `width/height`.
6. Общий максимум данных HTTP Range — **24 MiB**, весь ZIP размером ~2 GB не скачивается; нет файлов на диске, платных сервисов, credentials, user recordings, удаления или публикации изображений.
7. Формируется JSON только с техническими характеристиками: имена исследуемых файлов, SHA, размеры, классы/число bbox, фактически полученные байты. Не выводить сами изображения и содержимое XML.

## Границы доказательств
- Выборка по месту в алфавитном ZIP-каталоге может отражать пять групп имён, но **не доказывает независимые исходные видео, ульи, даты или сессии**.
- Считывание и проверка ZIP CRC/SHA нескольких JPEG не подтверждают **полное декодирование пикселей**, чистоту всех 4 993 изображений, независимое качество меток и пригодность для леткового подсчёта.
- Публикуемая на https://lila.science/datasets/boxes-on-bees-and-pollen лицензия **CDLA-Permissive** не является лицензией чужих модельных весов. Attribution и данные источника требуют дальнейшего учёта.
- **Не присваивать** `sourceVideoId`, `train`, `validation`, `test` по имени файла без документальных доказательств.
- Скрипт всегда сообщает `sourceVideoIdentityVerified=false`, `independentTrainTestSplitAvailable=false`, `jpegFullyDecoded=false`, `licenseVerified=false`, `trainingAuthorized=false`, `modelApproved=false`, `recognitionSucceeded=false`, `cleanupAuthorized=false`.
