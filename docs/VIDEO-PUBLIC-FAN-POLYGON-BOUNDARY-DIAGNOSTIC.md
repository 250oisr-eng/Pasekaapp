# Реальные переходы через авторскую область видео — не подсчёт пчёл на летке

## Два аутентичных исходника

Tomyslav Sledevic, *Labeled dataset for bee detection and direction estimation on beehive landing boards*, Mendeley Data v6, DOI `10.17632/8gb9r2yhfc.6`, CC BY 4.0. Из публичного каталога только:

- `tracks_20230711a-fan.txt` — 4 817 427 байт, SHA-256 `8446fe874e2cf89041542e8740ef8c1d85086605987e5740e763b0edd20cec12`;
- `entrance_zone_20230711a-fan.txt` — 70 байт, SHA-256 `23a339cef571975e18fdaafbb01c988c0e3ec4668bac7a491c8effe54ad50580`.

Размер и SHA-256 каждого файла сверяются **до** анализа; открывается только известный формат авторской зоны `polygon = np.array(...)`, исходные вершины в пикселях 1920×1080: `(100,220), (1860,270), (1805,590), (145,545)`. Используются именно эти координаты, не придуманная линия движения. Оригинальный MP4 **не загружается**, пиксельное распознавание не выполняется.

## Правило диагностики

`tools/audit_public_fan_polygon_transitions.py` для каждого из 6000 frame-id читает опубликованные GT bbox и track ID. Центр рамки классифицируется внутри/вне авторского многоугольника (граница включена). Сопоставляются только соседние кадры **с тем же опубликованным track ID**. Появление того же ID после кадра без наблюдения не считается пересечением: траектория внутри пропуска неизвестна. Если тот же ID пересёк границу назад в пределах двух кадров после другого перехода — отдельный диагностический счётчик, **не доказательство ошибочности** какого-либо конкретного пересечения.

Это анализ **зоны наблюдения**, а не попадания в отверстие летка. В Mendeley v6 поведенческие классы `foraging, defense, fanning, washboarding` не являются независимыми label события «пчела вошла/вышла». Нельзя определять `insideSide` пользовательского летка из положения автора polygon.
