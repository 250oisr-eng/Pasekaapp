# PWA shell v330 — актуализация offline-кода после семи слияний

Текущий Service Worker `v329` использует cache-first для JavaScript-модулей и network-first для навигации. После семи интеграций были изменены `equipment-inventory.js`, `varroa-monitor.js`, `pesticide-incident.js` и `index.html`, но SW оставался версии 329. Поэтому ранее установленное приложение могло продолжать получать **старые JS-модули из кэша** при открытии после обновления. Обновление `v330` создаёт полный новый кэш оболочки через проверку HTTP 200 и активирует его только при успешном завершении скачивания; obsolete строго версионированный `paseka-shell-v329` очищается. Все user caches, чужие имена, версии будущего и original video остаются нетронутыми.

Изменены `sw.js` и три файла регрессионных тестов версии/границ удаления: `tests/sw-cache-boundary.test.mjs`, `tests/service-worker-offline-lifecycle.test.mjs` и `tests/regression.test.mjs`. Первый CI-кодовый SHA `545b173` выявил две устаревшие проверки на `v329` (1206/1208 PASS); тесты согласованы с `v330` в `08ad0998`, без ослабления runtime-защиты. `tests/service-worker-install-private.test.mjs` продолжает проверять неразрешённые/private/partial HTTP-ответы; `tests/sw-cache-boundary.test.mjs` проверяет безопасную ротацию, `tests/service-worker-offline-lifecycle.test.mjs` — жизненный цикл установки и сохранность пользовательского кэша. Нет изменения IndexedDB, данных или B07 profile gate. Аппаратная проверка офлайн-навигации на OnePlus отдельно NOT_TESTED. Не запускать release/production deployment по этому PR.
