## Сценарий одного сеанса Windows + OnePlus

Рабочий комплект пользователя: `PASEKA_P0_OnePlus_PC_Audit_2026-11-24.zip`, отправлен непосредственно в текущем чате; **не находится в репозитории и не является GitHub release**. Комплект содержит:

- `ЗАПУСТИТЬ-ПРОВЕРКУ.cmd` → `run-p0-oneplus.ps1`: проверяет полный SHA APK по manifest и source GitHub SHA, единственное Android USB-устройство, Android API ≥35, правильный строго изолированный пакет `ru.paseka.journal.disasterproof`. При несовпадении STOP до установки.
- Только `adb install -r` **диагностического пакета**, запуск/просмотр логов, `adb shell am force-stop ru.paseka.journal.disasterproof`, повторный запуск. Без `pm clear` и `uninstall`, без копирования исходных пользовательских файлов.
- Отчёт `P0-RESULT-*/report.json`: model/API/manifest APK SHA/firstCode/secondCode, `PASS_ISOLATED_ONLY` либо BLOCKED. При уже существующей тестовой БД первая стадия `P0_DISASTER_WEBVIEW_RESTORE_PASS` **не повторяется**, что явно отмечается полем `firstRunFresh=false`.
- Сценарий опирается на официальный Platform-Tools и **не был отдельно запущен на Windows** во время этого аудита. Подлинный PASS физического OnePlus допустим только после пользовательского отчёта. Нельзя объявлять локальную установку совершённой по созданию файла ZIP.

**Участие пользователя:** перенести ZIP из GitHub Actions [#45356117524](https://github.com/250oisr-eng/Pasekaapp/actions/runs/45356117524) → Artifacts → `paseka-disaster-proof-isolated-apk` в папку Windows-комплекта, подключить OnePlus по USB, запустить CMD и передать только `report.json`. Нельзя просить пользователя прислать личные видео, полный архив или логи с персональными данными.

## После этого сеанса (не смешивать с smoke)

- **Физическое P0 для текущего APK:** статус до поступления `report.json` — `NOT_TESTED`.
- **Реальная G0 исходных медиа:** нельзя прочитать рабочую базу через отдельный Android-пакет из-за изоляции Android. Нужен согласованный *read-only* путь из самого рабочего origin либо экспорт с подтверждением пользователя; массовые ADB копии и обход sandbox запрещены.
- **Независимое восстановление:** нужна проверенная внешняя копия исходного архива и отдельный чистый физический приёмник, без изменения оригинальной базы и без публикации личных данных. Второй Android не подтверждён.
