# B01 — проверка внешнего полного архива: ограничение чтения файла

**25.11.2026.** Основа: `main=5158f31fe39d96dd54016286e536bd5aeec70755`. Контроль: `AGENTS.md`, `docs/PROJECT-CONTROL.md`, F0–F7. Безусловно `NO_RESTORE/NO_DEVICE/NO_NETWORK/NO_CLEANUP`.

## F0–F2: конкретный риск

В `scripts/verify-exported-archive.mjs` исходный код проверяет размер через `stat(path)`, а затем делает отдельный `readFile(path,'utf8')`. Файл на ПК может вырасти или быть подменён между stat и read: заявленный лимит 512 MiB не ограничивает фактические прочитанные байты. Символическая ссылка может перенаправлять проверку на другой файл. Это риск локальной памяти и ошибочной атрибуции свидетельства, **не** доказательство повреждения какого-либо реального архива.

## F3–F4: минимальное изменение

- Требовать обычный локальный файл, не ссылку; на платформах с поддержкой `O_NOFOLLOW` запрещать следование ссылке при открытии.
- Держать один read-only file descriptor с проверкой identity и metadata, читать по частям не более 1 MiB, останавливать чтение на `maxBytes+1`, проверять неизменность размера, `mtime`, `ctime` после чтения.
- Невалидный UTF-8 → BLOCKED. Не публиковать путь/содержимое, не передавать файлы и не изменять JSON.
- Сохранить `inspectArchive` production как валидатор SHA-256/схемы/содержимого. Бинарные Blob/видео обрабатываются только в in-memory fake-indexeddb.
- Никаких новых модулей в PWA, нового Service Worker, restore, runtime database migrations или удаления оригиналов.

## F5–F7: доказательство и ограничения

Регрессии: действительный сохранённый файл не изменён; превышенный byte cap не читает бесконтрольно; symlink и не-UTF8 отказывают. Проверить точные SHA Android + Governance и после разрешённого merge точный SHA main. Даже если тест пройдёт, результат **только** `EXPORTED_FILE_STRUCTURALLY_VERIFIED_RESTORE_NOT_TESTED`. Полная внешняя копия всех источников и независимое физическое восстановление по B01 **не подтверждены**. Для файлов сверх лимита требуется отдельный потоковый механизм; не объявлять их испорченными.
