# Тип и статус рамки — 27.11.2026

Явное требование владельца: foundation (вощина) и strip (полоска вощины) допускают только foundation (Вощина); comb (Сушь) допускает все 11 существующих статусов. При смене типа на foundation/strip статус устанавливается foundation; при смене на comb по умолчанию drawn. Статус не меняет тип автоматически. Проверка при сохранении, выборе другой рамки и перемещении через редактор. Старые несовместимые записи не мигрируются: требуется явное уточнение. История и аудит сохраняются. Схема БД неизменна. Вне scope: существующие исторические архивы, отдельные операции откачки, production. SW shell v326, тесты allowed/denied/legacy. Откат — revert этого PR, без изменений схемы.
