# B01 — независимая проверка экспортированного файла без восстановления (F0–F7)

**Основа:** `main=f106e2aa7990ecc5c5ebf99baf5a3c45c54738b1`, `js/disaster-archive.js` текущего `main`. Формат `paseka-idb-full-v1`, `payload.database=paseka-v1`, версия IDB **3**.

## F0–F2: недостающий путь
Главная зависимость сохранности оригиналов — файл архива должен быть сохранён **вне телефона** и проверен повторным чтением; ещё требуется реальный независимый restore на пустом тестовом окружении. В main есть `exportArchive`, `inspectArchive`, `verifyRestoredArchive`, но `inspectArchive` требует аргумент DB. Пользователю недопустимо запускать restore рабочей DB ради проверки внешнего JSON.

## F3–F4: локальный инструмент
Новый `scripts/verify-exported-archive.mjs` принимает **существующий** JSON-файл из полного P0 экспорта:
`node scripts/verify-exported-archive.mjs /path/to/your-local-full-archive.json`.

- Читает файл локально, не передаёт его в ChatGPT, GitHub или сеть.
- Создаёт **только пустую отдельную fake-indexeddb в памяти**, со схемой из архива, не открывает обычный `paseka-v1` браузера или приложения.
- Использует **исходную** `PasekaDisasterArchive.inspectArchive`: сверяет SHA-256 сериализованной полезной нагрузки, все заявленные stores (включая исторические дополнительные), counts, дубли ключей, метаданные и декодирование Blob/File/бинарных значений. Требует `main`, `full_backup`, `entrance_media`, принимает только версию 3.
- Не вызывает `atomicRestore`, не пишет реальную БД, не удаляет оригиналы, не развёртывает APK/PWA.
- Возвращает только status, manifest digest и число записей; не выводит пути/содержимое личных файлов в консоль. При ошибке CLI печатает только `FILE_NOT_VERIFIED` и ненулевой exit code.
- Для защиты памяти default 512 MiB: слишком большие файлы `BLOCKED`, **не** считаются испорченными. В этом случае требуется иной строго потоковый офлайн-валидатор.

## F5–F7: граница доказательства
Проверить синтетические и негативные сценарии плюс точный SHA CI. **`EXPORTED_FILE_STRUCTURALLY_VERIFIED_RESTORE_NOT_TESTED` НЕ ДОКАЗЫВАЕТ** реальное восстановление IndexedDB, охват Android Gallery/MediaStore, независимых приложений, метаданных ОС, фактическое сохранение полного оригинала или возможность удалить видео. B01 остаётся BLOCKED; #442 FROZEN. Реальный полный restore возможен только в пустой независимой среде при отдельном протоколе и разрешении.
