# Альтернативные независимые источники для видеоаналитики летка

Дата исследования: 2026-11-21. Основной приоритет: найти безопасно лицензированные данные, не ожидая ответа Nieves-Rivera et al. о 1194 событиях.

## Официальный CC BY 4.0 архив Monash: проверяемый аудит

Сведения получены по неизменённой записи версии **v1** через https://api.figshare.com/v2/articles/32315067 и https://api.figshare.com/v2/articles/32315067/files. Статус public, дата публикации 2026-05-27. Авторские исходники относятся к виду **Tetragonula carbonaria** (безжалые пчёлы), не к Apis mellifera. Отдельный репозиторий кода https://github.com/asadiceiu/native-bee-detection-tracking на commit `1138c1e754c4eea1887bd02217cc58e25973adb5` лицензирован **MIT для кода**; в его текущем дереве отсутствуют оригинальные data/файлы вопреки примеру пути из README. Поэтому архивы скачиваются *только у официального издателя*; лицензия MIT на код не переопределяет лицензию данных или весов моделей.

| Publisher file ID | Оригинальный файл | Байты | MD5 из официального metadata |
|---|---|---:|---|
| 64894983 | `native-bee-detection-dataset.zip` | 98810212 | `30c5261bf2a23668794d10ac8b040261` |
| 64894986 | `native-bee-tracking-dataset.zip` | 107325128 | `9c87d57716c879c2b569196ba4197021` |

**Важно:** MD5 из JSON описывает утверждение издателя. Только скачивание исходных байтов, проверка точного размера, реального MD5 и опубликование своего SHA256 делает проверяемым оригинальный ZIP; это отдельно выполняет tools/audit_licensed_native_bee_archive_manifest.py в эфемерном CI-каталоге. Не утверждать, что ZIP уже прошёл byte audit, пока точный workflow не завершился SUCCESS. ZIP не распаковывается на диск и не загружается в Git/артефакты; проверяются CRC и безопасные имена. Если файл изменился, проверка fail-closed.

**Разграничение качества:** наличие реальных JPEG + YOLO bbox/ID и проверенных zip bytes позволяет диагностировать фактическую разметку и отдельный tracker. Это не доказывает физических границ улья, направления, U-turn, валидности U/D событий, качества нейросети и независимой in/out точности. Датасет не может подменить авторское описание 1194 случаев. Лицензия CC BY 4.0 требует атрибуции; любые дополнительные права на конкретные веса/модели и зависимости необходимо проверить отдельно.

## Изменения в этой Draft-ветке

- `tools/audit_licensed_native_bee_dataset_metadata.py`: точные allowlisted JSON endpoints, проверка DOI, версии v1, CC BY 4.0, размеров, числа архивов, MD5; БЕЗ бинарного скачивания.
- `tests/test_audit_licensed_native_bee_dataset_metadata.py`: 16 fail-closed тестов на синтетических JSON и смену лицензии, хешей, версий и URL.
- `tools/audit_licensed_native_bee_archive_manifest.py`: дополнительный однократный read-only аудит настоящих ZIP в временной папке CI: точный размер и MD5, собственный SHA256, CRC, лимиты размерности и защита от небезопасных путей. Не распаковывает файлы, не переносит аннотации или изображения в Git.
- `tests/test_audit_licensed_native_bee_archive_manifest.py`: 9 синтетических ZIP и негативных сценариев.
- Workflows `test-licensed-native-bee-dataset-metadata.yml` и `test-licensed-native-bee-archives.yml`; второй делает тяжёлую исходниковую проверку только на событии push (не на каждом PR синхронизации), бесплатно и без платных сервисов.
