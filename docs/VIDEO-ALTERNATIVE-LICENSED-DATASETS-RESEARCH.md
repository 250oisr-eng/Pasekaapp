Дата исследования: 2026-11-21. Основной приоритет: найти безопасно лицензированные данные, не ожидая ответа Nieves-Rivera et al. о 1194 событиях.

## Реальные проверенные исходники и обнаруженное пересечение (2026-11-21)

На **код/test SHA `fb6572d2a48d7b2aaa481a2ea2806971cf0d0570`** реальный [GitHub CI #44916620453](https://github.com/250oisr-eng/Pasekaapp/actions/runs/44916620453) завершён **SUCCESS**: 14 синтетических негативных тестов, два оригинальных ZIP с совпадающими publisher MD5, дополнительно зафиксированными SHA-256, корректный ZIP CRC и read-only структурный анализ.

- Detection ZIP **98 810 212 байт**, SHA-256 `a92a0976bdbaeb5fa0dbd665ccc2107ee6c1089bde3367dfe0cf6a00fa723968`: 3277 JPG, 3277 TXT, 5550 строк класса numeric, 0 пустых TXT, 1 bbox вне геометрии изображения.
- Tracking ZIP **107 325 128 байт**, SHA-256 `fb79d8bb77cdedd394713d56396755314fa6446ecc2795dbce62a9da3109cd8b`: 3545 JPG, 3545 TXT, 5550 строк типа `bee_N`, 268 пустых TXT, 1 bbox вне геометрии.
- **Оба архива имеют 100% парность JPG/TXT**, 0 пропущенных соответствий, 0 строк с числом полей, отличным от пяти. В обоих **нет MP4**.
- **КРИТИЧЕСКИ ВАЖНО — утечка данных:** сравнение **SHA256 реальных JPG** показало, что **все 3277 detection JPG буквально побайтово присутствуют в tracking ZIP** (3277 совпадений из 3277, все JPG в каждом архиве уникальны по SHA256). 268 кадров присутствуют только в tracking ZIP. Поэтому **запрещено** обучать на целом detection ZIP, а tracking ZIP выдавать за независимый тест: данные пересекаются полностью по detection. Это подтверждённое побайтовое совпадение; доказательства независимости остальных 268 кадров/сессий нет.
- В описании статьи/датасета указаны **3511 оценочных tracking frames**, а в архиве 3545, разница **34**. Не отождествлять разницу без точного перечня 13 оценочных + 3 коротких последовательностей.
- Обнаруженная геометрическая ошибка — факт о **проверке исходной YOLO-разметки**, не причина переписывать оригиналы или автоматически исправлять координаты. Пустая GT-метка в кадре — не доказательство нулевого потока через леток.

**Следствие для следующего этапа:** сначала создать проверяемый по исходным сессиям/клипам manifest разделения train/test и исключить пересечение кадров, затем запускать реальный detector/tracker. Текущие исходники подтверждают лицензированную структурную разметку **другого вида**, но физически правильный Apis mellifera in/out и U-turn benchmark остаются не проверены.

## Официальный CC BY 4.0 архив Monash: проверяемый аудит

Сведения получены по неизменённой записи версии **v1** через https://api.figshare.com/v2/articles/32315067 и https://api.figshare.com/v2/articles/32315067/files. Статус public, дата публикации 2026-05-27. Авторские исходники относятся к виду **Tetragonula carbonaria** (безжалые пчёлы), не к Apis mellifera. Отдельный репозиторий кода https://github.com/asadiceiu/native-bee-detection-tracking на commit `1138c1e754c4eea1887bd02217cc58e25973adb5` лицензирован **MIT для кода**; в его текущем дереве отсутствуют оригинальные data/файлы вопреки примеру пути из README. Поэтому архивы скачиваются *только у официального издателя*; лицензия MIT на код не переопределяет лицензию данных или весов моделей.

| Publisher file ID | Оригинальный файл | Байты | MD5 из официального metadata |
|---|---|---:|---|
| 64894983 | `native-bee-detection-dataset.zip` | 98810212 | `30c5261bf2a23668794d10ac8b040261` |
| 64894986 | `native-bee-tracking-dataset.zip` | 107325128 | `9c87d57716c879c2b569196ba4197021` |

**Важно:** MD5 из JSON описывает утверждение издателя. Только скачивание исходных байтов, проверка точного размера, реального MD5 и опубликование своего SHA256 делает проверяемым оригинальный ZIP; это отдельно выполняет tools/audit_licensed_native_bee_archive_manifest.py в эфемерном CI-каталоге. Не утверждать, что ZIP уже прошёл byte audit, пока точный workflow не завершился SUCCESS. ZIP не распаковывается на диск и не загружается в Git/артефакты; проверяются CRC и безопасные имена. Если файл изменился, проверка fail-closed.

**Разграничение качества:** наличие реальных JPEG + YOLO bbox/ID и проверенных zip bytes позволяет диагностировать фактическую разметку и отдельный tracker. Это не доказывает физических границ улья, направления, U-turn, валидности U/D событий, качества нейросети и независимой in/out точности. Датасет не может подменить авторское описание 1194 случаев. Лицензия CC BY 4.0 требует атрибуции; любые дополнительные права на конкретные веса/модели и зависимости необходимо проверить отдельно.
