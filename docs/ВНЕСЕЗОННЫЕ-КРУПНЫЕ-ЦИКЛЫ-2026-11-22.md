# Внесезонная разработка крупными циклами — 22 ноября 2026

## Решение пользователя

В ноябре реальная съёмка пчёл невозможна. Не ожидать от пользователя тестовых видео, полевых проходов или физической верификации до фактического появления условий. Не устанавливать самостоятельно календарную дату возобновления полевых испытаний: пользователь сообщит о возможности съёмки. **Разработка при этом продолжается.**

Работать **крупными автономными логическими секциями**, не останавливаться после единичного коммита или задачи и не запрашивать «Продолжай» между стандартными шагами. Для каждого цикла: актуальные AGENTS/PROJECT-CONTROL/документы и GitHub SHA → аудит зависимостей → минимальная совместимая реализация → отрицательные и регрессионные тесты → CI/Android сборка на точном code SHA → документация/журнал → Draft PR и следующий независимый блок. Непроверенные и неуспешные этапы оставлять открытыми, не заявлять PASS без доказательств.

## Критерии готовности и темп

- Один крупный цикл включает связанные код + тесты + документы + проверенный CI + статус Draft PR; не плодить искусственно отдельное APK для каждого микротеста.
- Следующий цикл начинается автономно, если предыдущий безопасно завершён. При внешнем CI blocker (например, Maven HTTP 429) расследовать/перезапустить проверки и фиксировать оба исхода; не объявлять успех заранее.
- Пользователь участвует только для решений, требующих реальной технологии/доступа, либо для фактической полевой съёмки в подходящих условиях. Не просить повторять уже доказанные синтетические тесты.
- Главный измеритель прогресса — доказанная совместимость приложения и сохранность данных, а не количество открытых PR.
