# Пилот независимого локального AI code review — 2026-11-19

## Назначение и ограничения
Дополнительный инструмент разработки, а не функциональность приложения. Пилот принимает только явно подготовленный синтетический JSON `tests/fixtures/local-ai-review.json`. НЕ подключается к IndexedDB, архивам, GitHub Actions, UI, Service Worker или технологическим операциям. Ветка не меняет production. Любой результат модели — непроверенное замечание.

## Состав
- `scripts/local-ai-review.mjs`: изолированный Node.js CLI к локальному Ollama на `127.0.0.1:11434`, без API-ключей, облачного fallback, shell и права записи.
- `tests/local-ai-review.test.mjs`: mocked HTTP-тесты ограничений, отказов, безопасности и формирования запроса.
- `tests/fixtures/local-ai-review.json`: вымышленный дефект удаления несуществующего элемента.

## Запуск, только после установки Ollama владельцем ПК
```sh
node --test tests/local-ai-review.test.mjs
node scripts/local-ai-review.mjs --fixture tests/fixtures/local-ai-review.json --model qwen3:4b
node scripts/local-ai-review.mjs --fixture tests/fixtures/local-ai-review.json --model deepseek-r1:7b
```
Нужна предварительная установка моделей владельцем компьютера. Запросы отправляются моделям по одному. CLI ничего не устанавливает и не загружает. Если Ollama недоступен — выход с ошибкой без обращения в облако. Вторая модель необязательна. Имена моделей — кандидаты, а не доказательство установки или качества.

## Ограничения безопасности
- Максимум 12 000 байт контекста и 12 000 байт текста ответа; лимит генерации 700 токенов, таймаут 60 секунд.
- Проверка распространённых секретов (эвристика) и явно синтетического маркирования; НЕ гарантирует отсутствие скрытых секретов, персональных данных или prompt injection. Пользователь/разработчик обязан просмотреть фикстуру до запуска.
- Локальный процесс Ollama должен быть запущен владельцем ПК и доверенным; скрипт обращается только к loopback. Запуск на общем компьютере и экспонирование Ollama в сеть — вне пилота.
- Предлагаемые моделью команды не исполняются. Выход не проходит как доверенная валидация, не добавляется в автоматический merge gate.
- Никаких облачных провайдеров, платных тарифов, новых прав GitHub или GitHub secrets.
- Отключение: не запускать CLI. Для полного удаления удалить из рабочей ветки эти три новых файла и эту документацию.

## Проверка и границы результатов
Первоначально отдельно прогнаны четыре Node.js mocked tests: 4/4 PASS на локальной копии прототипа до отправки в GitHub. Для точного GitHub HEAD необходим новый CI/локальный запуск; Ollama, Qwen и DeepSeek на пользовательском Windows ПК не проверялись. Предложение о качестве моделей требует одинакового набора фикстур и ручной проверки дефектов, ложных срабатываний, скорости и использования памяти. Не считать исследование тарифов облачных API завершённым.
