# P1 UI — адресные доступные названия кнопок улья (выборочный перенос #187)

**F0–F2, 26.11.2026.** Проверен исторический корневой #187 с read-only mobile/browser UI-тестами и обширным редизайном `index.html`. На live `main=e1c60d6f6ea47ac2cdc1301e5b0a7d026a5077fb` уже есть общий делегированный `document.addEventListener('keydown')`, обслуживающий `.hive-row-main`, `.home-hive`, `.frame-chip` по Enter и Пробелу. Старые inline `onkeydown` из #187 не переносить: дублирование может вызывать двойное открытие.

**Подтверждённый пробел:** в каталоге ульев `aria-label="Открыть улей"` и одинаковые кнопки `Открыть`/`Удалить` не указывают, к какому улью относится действие. На телефоне при работе с экранным диктором это создаёт неоднозначность и риск выбора неправильного улья.

**F3:** только три атрибута `aria-label` в существующем шаблоне `hive-row`: у карточки, кнопки открытия и кнопки удаления — с `safe(hname(h.id))`. Обработчики `openHive`, `deleteHive` и связь `data-hive-id` **не изменены**. В регрессиях структурно проверить три названия и фактически выполнить действующий делегированный keyboard listener на синтетических событиях: Enter/Space → одно `click`, другие клавиши/некликабельные цели → ничего.

**F4:** Нет изменения расположения элементов, HTML-каркаса, сохранённых данных, профилей, миграций, Service Worker, запроса к сети, установки APK, видеопайплайна или физической операции. Старые `home-overview`/honeycomb/layout и Playwright/axe-пакеты из #187 не переносить без отдельной оценки текущего интерфейса и бесплатности тестов.
