## Обязательные правила

- Политика бесплатных средств обязательна для всех технических и продуктовых решений. До выбора сервиса сверяться с docs/ПОЛИТИКА-БЕСПЛАТНЫХ-СРЕДСТВ.md; платные опции и автоматические списания запрещены.
- `PROJECT_STATUS.md` — постоянный оперативный источник состояния. Обновлять после каждого логически завершённого этапа; не удалять историю важных изменений.
- В начале каждого сеанса сначала читать `PROJECT_STATUS.md`, затем сверять записанное с фактическими ветками, PR, commits, CI, кодом и состоянием БД.
- Ни один рабочий сеанс не считается завершённым, пока не зафиксированы актуальный статус и журнал изменений в соответствующих рабочих документах.
- Записывать только проверенные действия; неизвестное и непроверенное прямо помечать. Не хранить секреты.
- Документы управления не заменяют исходный DOCX. Если требуется заново проверить точную формулировку или смысл, открыть оригинальный источник.
