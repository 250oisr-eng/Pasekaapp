# Apis mellifera — независимая проверка настоящих авторских пяти folds (Zenodo 2026 v2)

Дата: 2026-11-21. Исследовательский статус: **реальные оригинальные списки/лицензия/проверка меток подтверждены байт-в-байт**, не загружено ни одного оригинального JPG, видео или веса. Не включать в production, модель и подсчёт входов.

## Источник и разрешения

Авторы Su, Gao, Lee, Wu; оригинал [Zenodo 2026 v2, DOI 10.5281/zenodo.23276947](https://doi.org/10.5281/zenodo.23276947), concept DOI 10.5281/zenodo.23099411, лицензия **CC BY 4.0**. В официальном описании **явно Apis mellifera**. Ссылка Zenodo ведёт на dataset `dataset_2823_images_labels.zip` около **2.0 ГБ**, а не «обученный детектор летка»; отдельный `weights.zip` ~734 МБ. Код, оригинальные разбиения, CSV подтверждения меток и `LICENSE` опубликованы авторами также в https://github.com/Soda0603/varroa-in-hive-imaging, зафиксирован точный upstream Git commit:

`136cc6fefa993719131128132bb7c0a4deccbad9`

Первичные авторские данные: 2823 JPEG-кадра с YOLO bbox, **2795** внутри колонии *Apis mellifera* (камера на рельсе, 9 дат) плюс **28** отдельных handheld-фото. Разметка: class 0 — пчела без **видимого** клеща, class 1 — пчела с видимым клещом. **Граница рамки охватывает пчелу, а не клеща**, класс 0 не доказывает отсутствие заражения. Никаких подтверждённых событий in/out летка, U-turn и калиброванной границы. В оригинальном README отдельно отмечена проблема EXIF orientation=6 у 13 фото и рассинхронизации 48 bbox при автоматическом повороте; при реальной оценке ориентацию требуется удерживать в авторских координатах.

Утверждённая лицензия исходных фотографий, кода и весов — CC BY 4.0 по авторскому GitHub `LICENSE` и Zenodo v2; сохранить авторскую атрибуцию, ссылку и информацию об изменениях. Однако **право использовать источник не является готовностью к обучению или мерилом качества**, нет проверки самих JPG, их размеров/sha или source-session идентичности.

## Воспроизводимый аудит оригинальных списков

Точный порядок: `tools/audit_apis_zenodo_real_split_lists.py` загружает **только 10 TXT, `README.md`, `LICENSE` и CSV reinspection** из *фиксированного upstream commit* по точным allowlisted URL `raw.githubusercontent.com`. Для каждого загруженного файла проверяется **оригинальный Git blob SHA1** (`sha1("blob <size>\\0"+bytes)`). Не скачивает 2-ГБ ZIP, веса, изображения, пользовательские видео и ничего не записывает в Git/артефакты.

Оригинальные списки разделяют 2823 идентификатора на 5 folds:

| Fold | Train, кадров | Validation, кадров | Прямых совпадений имён между train и val | Совпадающих дат по имени файла |
|---:|---:|---:|---:|---:|
| 1 | 2254 | 569 | 0 | 9 |
| 2 | 2257 | 566 | 0 | 9 |
| 3 | 2258 | 565 | 0 | 9 |
| 4 | 2260 | 563 | 0 | 9 |
| 5 | 2263 | 560 | 0 | 9 |

Фактические 9 дат, извлечённые только из имён `img-YYYYMMDD_HHMMSS--N.jpg`: **2024-01-07, 2024-01-09, 2024-01-10, 2024-01-16, 2024-01-17, 2024-03-05, 2024-03-06, 2024-03-07, 2024-03-08**. Все девять присутствуют **в train и validation в каждом fold**. Уникальные 2823 image IDs, каждый ровно один раз попадает в validation одного fold. Нестационарные handheld-изображения также попадают в оба набора (по folds train 22/22/22/23/23, val 6/6/6/5/5).

**Проверенная граница интерпретации:** это настоящий overlap **по датам, выведенным из оригинальных имён файлов**. Нет одинаковых имён в train и val одного fold. Эти данные **не устанавливают**, что все кадры одной даты происходят из одной физической беспрерывной видеосессии или что разные даты независимы. Однако исходное разделение гарантированно **не является day-held-out**. Поэтому нельзя выдавать оригинальную 5-fold оценку за независимый по дням или сессиям тест будущего детектора «Пасека».

### Надёжность размеченного Varroa GT

Оригинальный авторский `verification/inhive_class1_verification.csv` содержит 23 строки для 23 in-hive class-1 bbox. Авторская повторная проверка: **3 с видимым клещом, 20 без подтверждённого клеща**. Результат не равен характеристике нашего приложения и не может быть подменён на «23 заражённые пчелы». Случаи с обычными пчёлами, объекты `bee` и `mite` следует различать. Данный источник **не заменяет** видовую/полевую калибровку для наружных летков.

## Допуск к следующим этапам — только Apis mellifera

1. **Реальные изображения:** по возможности получить первичный `dataset_2823_images_labels.zip` Zenodo v2 (с указанием официальных checksum и SHA, объём около 2 ГБ), ввести безопасный read-only аудит JPEG/YOLO. Не загружать архив в GitHub, не перекладывать в приложение и не хранить пользовательские фото.
2. **Независимая оценка:** спроектировать явные day-held-out (и лучше camera/session-held-out) folds, исключить близкие повторные кадры между train и test по *фактическим* image SHA/perceptual resemblance. Handheld 28 кадров оценивать отдельно; не смешивать их со слежением внутри улья.
3. **Модель детекции:** источник пригоден только для отдельной проверки Apis mellifera bbox при подтверждении всех прав зависимостей/весов и источниковых JPEG; не заявлять готовность реального offline Android inference.
4. **Физические in/out:** нужен отдельный Apis mellifera GT видеособытий, подтверждённая линия летка, проверка разворотов, надёжная ID tracking и измерение false +/-.
5. **Удаление видео:** подтверждение **реально успешного распознавания** в приложении — отдельный локальный safety-gate. Ни этот скрипт, ни сторонняя статья, ни успешный CI **не дают разрешение удалять медиа**, не меняют IndexedDB/backup/SW и пользовательские записи.
