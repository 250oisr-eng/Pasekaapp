### Дополнительная регрессия — безопасные ID в HTML обработчиках

В старом HTML ID видео подставлялся прямо в JS-строку обработчика `onclick="viewEntranceVideo('…')"` и `removeEntranceVideo('…')`. HTML-экранирование не гарантирует безопасность JavaScript после декодирования сущностей браузером.
