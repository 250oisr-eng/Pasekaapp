# P1 — список видео: защита от устаревшего асинхронного ответа (25.11.2026)

## F0–F2
В `main=fdcca080b68aa5b0014b8e99cd3e4f1d428e7ba2` функция `refreshEntranceVideos()` после `await listEntranceVideos()` выводит список для улья, выбранного **до ожидания**. Быстрый переход «улей A → улей B» может привести к тому, что завершившаяся позже старая выборка A перезапишет уже актуальный экран B. Поздний отказ чтения способен заменить актуальный список старым текстом ошибки. Это ошибка представления, не подтверждённая потеря файлов.

F2 = LIMITED_SAFE_DRAFT. Исправление только UI, без внесения пользовательских данных в Git, без доступа к устройству, реальной пасеке, IndexedDB schema и оригиналам видео.
