# P1 UI — сохранение одной строки рамок корпуса (выборочный #187)

**F0–F2 / 26.11.2026.** База перед изменением `main=9bf11cc697ed6b8645f97e4ff5d8b9d19a3b397c`. Исторический root [#187](https://github.com/250oisr-eng/Pasekaapp/pull/187) предлагал динамический счётчик колонок, но вместе с большим редизайном и устаревшими inline keyboard handlers. [#587](https://github.com/250oisr-eng/Pasekaapp/pull/587) уже выборочно интегрировал независимые названия действий ульев. До исправления в `index.html` существовало `.frame-strip{display:grid;grid-template-columns:repeat(6,minmax(0,1fr))...}`, а три активных обработчика показывают `box.frames`, `x.frames`, `b.frames` с непостоянной длиной. Для длинного массива рамок браузер размещает остаток во второй строке. Это баг **визуального представления**, не норматив о физическом числе рамок.

## Сценарий / контракт
- Пользователь открывает схему своего улья; все учтённые рамки одного гнездового корпуса остаются **в одной горизонтальной последовательности**, не переносятся в другую строку; при узком экране внутренняя полоска прокручивается по горизонтали.
- CSS-колонки вычисляются из `frames.length` для **трёх** существующих рендереров, включая 0 (без пустого grid count) и обычные 6/10, с минимумом 25px для каждой рамки. Не создавать/удалять/менять массив рамок и их статус. Физическую вместимость определяет существующий профиль и валидатор — данный CSS ничего о ней не утверждает.
- Сохранить `frameChip` и текущий общий делегированный `keydown` без inline-handler (избежать двойной активации). Медовые полосы с отдельным `.honey-strip` и размеры корпусов не менять.
- Затронуты только `index.html`, адресный `tests/frame-strip-count-main.test.mjs`, карточка/журнал/статус. **Никаких** новых npm зависимостей, сетевых запросов, API, хранилищ, миграций, физической операции или ИИ.
- Действующие IndexedDB, backup/restore, Service Worker `v323` неизменны. Для нового offline shell с живым клиентским кешем потребуется проверка процедуры обновления при отдельном релизе; этот код не объявляется установленным на телефоне.
