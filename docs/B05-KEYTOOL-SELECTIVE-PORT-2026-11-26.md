# B05 — выборочный перенос read-only проверки keytool из исторического PR #519

**F0–F2, 26.11.2026.** В актуальном main `e2b4aac12774882fa52b28275a5d1e0e7ff05c53` отсутствует `scripts/check-b05-keytool-certificate.mjs`, а старый #519 содержит устаревшие статусы. Полезное изменение переносится отдельно: локальная **только метаданная** проверка одного сертификата `PrivateKeyEntry`, без доступа к keystore через приложение.

**Область F3–F4.** Скрипт читает только текст `keytool -list -v -alias` через stdin, не принимает пароли, пути к хранилищам и ключи в аргументах. Должны присутствовать ровно один Alias name, один Entry type, один корректный SHA256. Несколько алиасов, несколько отпечатков, неподходящий тип, несовпадение или усечённый SHA блокируются. В ответе нет имён алиасов. Даже совпадение `PrivateKeyEntry` возвращает `canSignApk:false, backupVerified:false, installationAuthorized:false`.

Добавлен `.gitignore` для локальных файлов секретов и ключей; это не удаляет уже отслеживаемые Git файлы и не заменяет секретный аудит. Оригинальные файлы, private keystore, production и OnePlus не открывались и не передавались в CI. Фикстуры тестов синтетические.

**F5–F7.** Доказательством кода являются CI и negative tests на точном SHA нового PR. Сходство сертификата с установленной версией само по себе **не подтверждает** наличие закрытого ключа, его сохранность, возможность обновления, безопасный откат, B01 full restore или разрешение на установку APK. B04/B05 остаются BLOCKED; #442 FROZEN. Старый #519 закрывать только после проверки, безопасного слияния и сохранения ветки/истории.
