Секция не угадывается: показывать только зарегистрированные позиции корпуса с однозначным family ID. История семьи сохраняется.

Неподготовленный профиль не активировать. Для рамки: номер позиции, известный код, записанный статус либо «Не указан», доступная подпись; не превращать модельную вощину в наблюдение. Не создавать новых операций/обходов блокировок: штатный редактор и валидаторы. 
Без новых API, платных ресурсов, изменения физической модели, схемы IndexedDB, Service Worker, OP, истории, ИИ/видео, архивов.
