# OnePlus 10 Pro — независимый QA APK текущей версии

Дата подготовки: 27.11.2026. **F0–F2: LIMITED_SAFE_DRAFT**. База: `main=14b398c97354800062b170e835a97bf7c76b7eb5` после интеграции истории семьи #612. Источник реализации: выборочно перенесённый технически изолированный проверенный workflow старого Draft #602 (не сливать его устаревшие файлы и статусы).

## Назначение

Завершить все возможные автоматические этапы перед началом реального пользовательского испытания на OnePlus. CI собирает **только отдельный тестовый пакет `ru.paseka.journal.qa`**, название «Пасека QA — тест», собственная песочница. Не затрагивать установленный `ru.paseka.journal` и существующие данные, видео/галерею, backup и подпись production. Никаких удалений, переустановок или миграций рабочего пакета.

## Автоматические технические ворота

`.github/workflows/android-qa-isolated.yml`: checkout точного SHA → npm test → `npm run web:prepare` → только во временной рабочей копии изменение `capacitor.config.json` посредством `scripts/prepare-android-qa-config.mjs` → Capacitor Android API 35 → debug APK → независимая aapt `applicationId`, apksigner сертификат, SHA-256 и CI source SHA. Выходной артефакт `PASEKA-ONEPLUS-ISOLATED-QA-APK` содержит `PASEKA-ONEPLUS-QA-ONLY.apk`, `QA-PROVENANCE.json` и `README-QA-ONLY.txt`. Срок хранения CI 7 дней. Никакой публикации Pages/Cloudflare.

**Fail closed:** если package не равен `ru.paseka.journal.qa`, signer/хеш/привязка SHA неизвестны, подпись недостоверна, Android конфигурация WebView разрешает remote/mixed content, CI неуспешен — не устанавливать.

QA debug signer может меняться от сборки к сборке. **Не обновлять QA поверх старой версии с искусственными данными**, предварительно экспортировать их или использовать отдельный новый чистый экземпляр по плану. Не использовать APK QA как update production.

## Физические циклы (только после успешного binary proof)

1. **Аппаратный запуск и навигация:** пользователь устанавливает отдельный QA APK после сверки package/hash. Открывает только QA, подтверждает пустую тестовую пасеку; проверяет 4–3–4 соты, доступность кнопок/центральной пчелы, вкладки, Back, поворот, работу одним пальцем и видимость в ярком свете. Записывает PASS/FAIL по каждому пункту. Никаких настоящих данных.
2. **Искусственная запись и автономность:** один синтетический улей поддерживаемого профиля, одна запись `QA-НЕФАКТИЧЕСКАЯ`, поиск, история семьи, возврат к улью. Проверка записи/повторного открытия, авиарежима, холодного запуска без сети, отсутствия дублирования. Не завершать реальные OP.
3. **Изолированное резервное копирование:** только внутри QA открыть экспорт, получить настоящий внешний архив тестовой базы, read-only проверить размер/структуру/SHA и создать отдельную внешнюю копию. Доказательство реального полного независимого восстановления production по-прежнему отсутствует (B01 BLOCKED).
4. **Необязательный аппаратный медиа-smoke:** только если доступен отдельный безопасный тестовый путь и ресурсы, разрешён короткий нейтральный клип без реальных пчёл. Запрещены автоудаление, запуск недоказанного детектора и загрузка чужого видео. Реальное распознавание не проверяется.

## Граница испытаний

Сборка в GitHub, Node и Chromium не доказывают установку/долговечное IndexedDB/физический offline/TalkBack/камеру на OnePlus. На физическом устройстве нужна отдельная обратная связь пользователя: версия Android, SHA файла, циклы PASS/FAIL и обезличенные ошибки. Никаких паролей, ключей, реальных координат или данных пасеки в отчёте.

**Пока физическое устройство не проверено:** `DEVICE_NOT_TESTED`; B01/B04/B05 остаются BLOCKED, #442 V0–V6 FROZEN. Обычная публикация/production deployment по текущему разрешению не выполняются.
