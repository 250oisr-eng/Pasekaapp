# Независимые предсказания детектора у летка: входной шлюз (2026-11-21)

**Статус:** тестовый офлайн-инструмент, не модель, не мобильное распознавание и не разрешение на удаление видео. Основа — Draft #298 с проверенным геометрическим tracking baseline. Этот инструмент отделяет фактически полученные внешние рамки детектора от готовой авторской tracking-разметки.

## Входные данные

`tools/evaluate_external_fan_detections.py` принимает пять обязательных аргументов:

1. Каталог с **реальными исходными байтами** `20230711a-fan.mp4` и `tracks_20230711a-fan.txt` из Mendeley v6.
2. Путь к **тому же** локальному MP4, его SHA должен совпадать с издательским `e0f3a7b1bd2b70ddc333f8caa17c7f029687dab2ea911ac7aff3902e4d5ad3cc`.
3. Путь к локальным весам модели. Файл **не исполняется**.
4. Ожидаемый SHA-256 весов модели, полученный из независимо проверенного источника. Сопоставление хэша само по себе не подтверждает лицензию или происхождение модели.
5. Отдельный локальный файл предсказаний JSONL, полученный внешним inference. Вызов **не запускает модель** и не доказывает причинную связь предсказаний с данными весами.

Файл предсказаний — ровно 6000 строк, включая пустые кадры, кадры имеют номера от 1 до 6000 без пропусков и дублей:

```jsonl
{"frame":1,"detections":[{"box":[0.1,0.2,0.3,0.4],"confidence":0.93}]}
{"frame":2,"detections":[]}
```

Это иллюстрация формата, **не** настоящие выходы модели. `box` — нормированные абсолютные координаты углов `[x1,y1,x2,y2]`, а не YOLO x-center/width; `confidence` — конечное число в пределах [0,1]. По умолчанию допускаются только confidence ≥0.50, порог изменяется `--min-confidence`. На кадр допустимо не больше 128 обнаружений; размер файла до 32 MiB. Не допускаются дополнительные поля (`track_id`, `groundTruth`, `accuracy`, `modelValidated`, `sourceSha256` и т. д.), бесконечности, NaN, ошибки геометрии, отсутствующие/повторные кадры, symlink или пустой файл.

Команда (при наличии реальных, независимо полученных файлов):

```sh
python tools/evaluate_external_fan_detections.py /path/original-v6 \
  /path/original-v6/20230711a-fan.mp4 \
  /path/verified-model.onnx \
  <verified-model-sha256> \
  /path/real-inference-predictions.jsonl --min-confidence 0.5
```

## Что считается результатом

После проверки MP4 и tracking TXT по издательским SHA и весов по указанному SHA программа сопоставляет реально поданные рамки с авторскими метками и запускает исследовательский трекер с памятью на один пропуск. Она возвращает рамочные `matched/missed/extra/meanMatchedIoU` и `adjacentIdSwitches` на 6000 кадрах. Эти показатели — **проверка предоставленных bbox относительно одного клипа**, а не доказательство независимости train/test или работоспособности модели на Android.

Даже если вычисленные `matched` окажутся идеальными, вывод **всегда** содержит `predictionsGeneratedByModelVerified=false`, `modelLicenseVerified=false`, `independentTestSplitVerified=false`, `realDetectorValidated=false`, `entranceLineCrossingsValidated=false`, `androidOfflineInferenceVerified=false`, `videoCleanupAuthorized=false`.

Причина: наличие байтов видео, весов и заявленных bbox не доказывает, что предсказания получены **именно этими** весами из этого MP4, что весам разрешено распространение, что набор независим от обучения или что качество приемлемо при другом улье/освещении. Эти доказательства требуются отдельно.

## Безопасность и границы изменений

Только локальное чтение указанных входных данных. Скрипт не устанавливает зависимости, не скачивает веса, не запускает сторонний inference, не пишет в IndexedDB, не изменяет историю пчелиных семей, не удаляет оригинальные пользовательские видео. `tests/test_evaluate_external_fan_detections.py` проверяет типы, дубликаты, отрицательные сценарии, полный охват кадров, порог уверенности, SHA и запрет преждевременного успеха. Специализированный CI исполняет только синтетические тесты; **реальная модель не проверена**.

**Следующий самостоятельный этап:** получить законные, лицензионно проверенные веса/спецификацию, подтверждённую независимость набора, выполнить настоящий фиксированный inference на оригинальном публичном MP4 и сохранить выходные JSONL + модельный SHA + конфигурацию воспроизведения для последующей сверки. Без этого запуск распознавания и автоматическое удаление видео недопустимы.
