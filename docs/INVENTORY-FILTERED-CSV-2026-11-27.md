# F0–F7 · Экспорт отфильтрованных физических корпусов в CSV

Классификация: независимая пользовательская функция учёта оборудования, **не** технология пчеловодства, OP и не backup/restore.

## F0 — пользовательский сценарий и существующие средства

Пчеловод открывает «Ещё» → «Инвентарь физических корпусов», задаёт уже существующие фильтры (поиск, тип, состояние, место), нажимает **«Скачать CSV по фильтрам»** и получает таблицу **только видимых** корпусов. Файл годится для проверки складских остатков и подготовки списка ремонта на телефоне/ПК; содержимое доступно офлайн.

До изменения в `main` существовали подробные карточки, поиск/фильтры и сводка, но не было выгрузки выборки; CSV журнала не содержит реестр физических корпусов. Соседние Draft #601 (сверка физических меток), #630 (OP02), #631 (журнал), #632 (реестр маток) не реализуют этот scope. **Прямой перенос чужого stacked PR не нужен.**

## F1/F2 — ресурсы, безопасность, контракт

- Ресурсы: локальное состояние `S.equipmentInventory.bodies`, `PasekaInventory.locateBody`, `inventoryBodyFrameCount`, постоянный код `PasekaLabels`, существующая UI выборка с атрибутом `hidden`. Внешние серверы/права/модели, геометрия секционного профиля и новое место хранения не нужны. Решение: `LIMITED_SAFE_DRAFT`.
- Только явное нажатие, данные **не изменяются**; никаких записей IndexedDB, Service Worker, резервных копий, событий инвентаря, операций OP. Экспорт CSV **не является архивом** и не может использоваться для восстановления пасеки.
- Схема: `UTF-8 BOM`, разделитель `;`, `CRLF`, двойные кавычки; колонки: код, тип, состояние, местонахождение, число рамок, комплект, физический ID, примечание. Для секционных корпусов число рамок остаётся **«не учитываются»**, поскольку физическая модель B07 ещё заблокирована. Нельзя заменять неизвестное значение `0`.
- CSV formula injection: значения с первыми `= + - @`, включая невидимые Unicode/пробельные префиксы, получают начальный апостроф до CSV-экранирования. Безавторизационный экспорт не отправляет файл в сеть, но всё равно содержит текст пользователя — только локальная загрузка.
- Сломанный/повторный ID, неизвестное состояние/тип, некорректное количество рамок и неоднозначное расположение → отклонить **весь** CSV, не выдавать частичную таблицу. Пустая выборка → сообщение, без файла. Никаких записей для подмены или «самовосстановления».
