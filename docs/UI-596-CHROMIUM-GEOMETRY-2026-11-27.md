## F3–F4: неизменяемые инварианты и реализация

- 11 существующих маршрутов, один AI в нижнем nav, `aria-current`/фокус, справка о виртуальной модели, журнал и семейная история сохраняются.
- Ни одна кнопка не перекрывает область нажатия другой; размеры каждого прямоугольника ≥44×44 CSS px и центр попадает в её DOM.
- AI визуально по центру nav; нет горизонтального переполнения; нижний padding контента не меньше высоты фиксированной панели. CSS использует `safe-area-inset-bottom` без заявления о физическом Android.
- **Синтетический baseline Chromium:** [run #45952861725](https://github.com/250oisr-eng/Pasekaapp/actions/runs/45952861725) **FAIL**, пересечение кнопки «Ульи» и AI на 11–14 px при 320/360/390/412px. Причина — исторический `translateY(-12px/-14px)`, который остался у `button[data-tab="ai"]` после нового grid.
- **Исправление:** в последнем scoped CSS AI `transform:none!important`, мобильная AI высота 56px равна строке, ширина `min(64px,100%)`; desktop ширина ограничена `min(68px,100%)`, tiny-screen `min(58px,100%)`. Старые код, миграции, JS-переходы и данные не тронуты.
- Добавлен `tests/e2e/navigation-layout.e2e.cjs`; запуск реального Chromium подключён к имеющемуся `.github/workflows/e2e-journal.yml`. Отдельных новых CI/платных зависимостей нет; workflow срабатывает на изменение `index.html` и E2E скриптов.
