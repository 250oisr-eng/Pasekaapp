## Дополнительный аудит зависимостей сборки

- В текущем `main` файл `package-lock.json` **отсутствует** (GitHub contents 404 и дерево Git). В `package.json` перечислены 2 runtime и 2 dev прямые зависимости с точными версиями; это не доказывает закрепление всех транзитивных версий.
- `.github/workflows/quality.yml` запускает `npm install --no-audit --no-fund`, а не `npm ci`; кэш npm ключуется по `package.json`. Следовательно, воспроизводимость транзитивной установки по lockfile не гарантирована. Сеть и полный реестр транзитивных пакетов в этом цикле не проверялись.
- **Нельзя** автоматически удалить пакеты Capacitor, fake-indexeddb или иные транзитивные пакеты без проверки использования и Android build. Следующий безопасный шаг — main-based отдельный Draft для создания валидного lockfile, проверки `npm ci`, тестов и Android сборки. Никаких обновлений пакетов без проверки совместимости.
