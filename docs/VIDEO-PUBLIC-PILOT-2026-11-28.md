## Этап 2 — реальный ограниченный эксперимент
`tools/run_public_bee_query_head_pilot.py`: действительный RF-DETR inference на оригинальных пикселях (без GT во входе), frozen COCO query embeddings + обучаемый отдельно на июньских кадрах бинарный линейный классификатор кандидатов. Это не full detector fine-tune и не готовый счётчик. Июльский ролик не участвует в нормализации, обучении, выборе threshold или модели; третья native запись оставлена для дальнейшего контрольного опыта. Проверяются SHA/size двух оригинальных MP4/TXT, различие source SHA, отсутствие совпадающих sampled frame hashes, реальные декодированные кадры, полная геометрия bbox. **Физическая независимость и полнота меток вне зоны летка остаются неизвестными**.
- 8 фиксированно выбранных annotated frames June, 3 July, фиксированная сетка 5×3 tiles. GT center однозначно относится к tile, геометрия обрезана по её краям. Метрики **tile-level author bbox**, не фактические полные counts или direction.
- Для обучения positive proposal IoU≥0.30, negative IoU≤0.10, промежуточные исключаются. Минимум 10/10 примеров и positives на ≥2 кадрах, иначе честный STOP. CPU-only, 100 шагов binary linear head, фиксированный seed. Базовая модель не меняется. Никаких данных/подсказок о GT в inference.
- На held-out recording предварительно фиксированы score thresholds 0.50/0.80, NMS IoU=0.50, matching IoU=0.50, максимальное число однозначных совпадений; precision/recall/F1/TP/FP/FN и proposal recall upper bound. Не выбирать «успешный» threshold после теста как независимое доказательство. Числа не утверждать до CI.
- Pinned Transformers 5.11.0, PyTorch 2.8.0 CPU/torchvision 0.23.0, Pillow, numpy, scipy; no paid accelerators, ephemeral dependency install only. Config pin original model revision, corrected processor `9f201577d9415f0378084748d27e68586e6b3600`. Input 384×384. Отдельный script/tests, не runtime приложения.
- **STOP** если model/annotation/source mismatch, невозможна CPU inference, нет положительных кандидатов. Результат даже при успешном эксперименте не закрывает V1/V2, product training authorization, actual IN/OUT event GT, physical Android/backup/cleanup. Не активировать производство, не удалять оригиналы.
