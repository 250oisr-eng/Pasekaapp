## Публикация и исходный репозиторий

- Andrea Nieves-Rivera, Marie Lluberes-Contreras, Rémi Mégret, *The Relevance of Compound Events in Bee Traffic Monitoring*, Informatics 2026, 13(5), 65. DOI: https://doi.org/10.3390/informatics13050065.
- Репозиторий, на который ссылается публикация: https://github.com/lablluberes/beeClassificationMethods.
- Проверенный **неизменяемый commit**: `295948bb398054684b7b92c18b7bb44ba37566af`, публичная ветка `main` на момент аудита.
- GitHub API на проверенной контрольной точке показывает **`license=null`**, а в дерево файлов (3833 файла: 3539 PNG, 291 CSV, 2 TXT и README) не входит `LICENSE`/эквивалент. **Нельзя выводить права на переиспользование, обучение или распространение из открытого доступа к репозиторию или лицензии статьи.**
- В дереве отсутствуют исходные MP4 — CSV *ссылаются* на записи, но самих оригинальных видео здесь не содержат. Нет SHA256 видеобайтов или доказательства самостоятельной исходной сессии, нет подтверждённого типа калиброванной физической линии летка.

Публикация описывает 1421 кластеризованное событие после соединения треков и **1194** событий, использованных после очистки для ручной оценки четырёх направлений. Однако в текущем репозитории две исходные CSV по **1422** строк. Из опубликованных файлов не выявлено авторитетного правила, автоматически воспроизводящего именно 1194 событий. Эти числа **не следует механически отождествлять**.

## Оригинальные таблицы — криптографическая идентичность

Новый `tools/audit_public_bee_manual_event_tables.py` бесплатно читает только два явных публичных URL `raw.githubusercontent.com` с закреплённым Git commit. В исходном проекте не сохраняет таблицы, события или изображения. Сначала ограничивает размер каждого ответа до 192 KiB, проверяет оригинальный Git blob identity и **SHA256**, затем строго читает 17 CSV полей, требует уникальные `group_id=0…1421` и фиксирует агрегаты.

| Таблица | Исходный размер | SHA-256 |
|---|---:|---|
| `month_data/5seconds_20260406_234425.csv` | 159902 байт | `8d5ef1db7e742849d018c79ab8ad27cf3828518750e68aacac22ee1bf2b70d07` |
| `month_data/5seconds_remi_frames_20260407_135801.csv` | 170808 байт | `51cbd31c6638dac8ebbc2b0069b441aec64bb5355edd52351ea70a45cecea059` |

Сравнение по `group_id` даёт 1422 парных строк, **177 отличий в `event`**, при этом `eventid` и имя `video` совпали в каждой паре. Эти различия отражают **разные опубликованные варианты аннотаций**, а не автоматически ошибку первого или истинность второго. Без описания авторов нельзя считать вторую CSV окончательным ground truth.

**Кодовая книга не подтверждена независимой проверкой**: статья описывает физическое движение вверх/вниз и четыре класса «вход/выход, вход→выход, выход→вход», но файл README не задаёт подтверждённое сопоставление `D/U/DU/UD` с конкретным направлением «внутрь улья», особенно при разных ракурсах. Преобразование этих кодов в продуктовые in/out по умолчанию запрещено. Пробелы `x` и пустые метки тоже не являются доказательством физического события.

## Проверка качества и граница использования

- Отдельные столбцы `ambiguousflag`, `error`, `complex`, `short_interruption`, `to_review`, `labelbee_valid` встречаются в исходных строках; **семантика пустого значения / True / x / комментария требует авторского описания**. Вариант CSV имеет отличающееся количество заполненных полей. Простое исключение строк с флагами без подтверждения правила не воспроизводит 1194 авторских события.
- Публикация анализирует **составные события и развороты**, поэтому будущая проверка счётчика не должна автоматически превращать `DU` или `UD` в одно простое `in`/`out`, считать два события или удалять их без определения целевой метрики.
- Аудит не скачивает исходные видео, не запускает модель, не выполняет inference и не оценивает точность пчеловодческого приложения. Строки CSV не копируются в тестовые fixtures, историю пасеки, базы, backup или клиентский пакет.
- `permissionToRedistributeSourceEventsVerified=false`, `physicalVideoSourceBytesVerified=false`, `final1194EventSubsetReproduced=false`, `manualEventGroundTruthIndependentOfModelVerified=false`, `independentValidationAuthorized=false`, `realBeeTrafficAccuracyMeasured=false`, `beeRecognitionSucceeded=false`, `videoCleanupAuthorized=false`.
- Воспроизводимость: `python -m unittest discover -s tests -p 'test_audit_public_bee_manual_event_tables.py' -v` и `python tools/audit_public_bee_manual_event_tables.py`; никаких зависимостей и платных API. CI закрепляет и размеры/контрольные суммы, и **агрегаты**, но сам по себе не доказывает лицензии или физическое соответствие оригинальным MP4.

**Следующий приоритет:** получить авторское описание кодов и фильтров итоговых 1194 событий, реальные исходные видео/их SHA и разрешения на воспроизведение/использование разметки. После этого отдельный независимый benchmark compound in/out и только затем on-device detector/tracker. Никакого разрешения удалять личные видео не создаётся.
