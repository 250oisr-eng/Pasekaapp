# Кандидат на бесплатную модель обнаружения пчёл — собственное обучение на открытой архитектуре

Дата: 2026-11-20. Статус: **техническая исследовательская альтернатива; никакие веса не выбраны и не обучены**.

## Почему нужен альтернативный путь
- У сторонних готовых YOLOv5/YOLOv8 honeybee checkpoint нет совместно подтверждённых прав на конкретные веса, upstream checkpoint и данные для предполагаемого распространения с приложением.
- Существующие классификаторы отдельных изображений не решают задачу bbox detection + временной tracking + пересечения линии летка.
- Для offline-first приложения нужен local CPU/WASM inference, не зависящий от облачной оплаты.

## Состав потенциально бесплатного стека
1. **YOLOX (Megvii-BaseDetection)** — официальный репозиторий https://github.com/Megvii-BaseDetection/YOLOX и лицензия https://github.com/Megvii-BaseDetection/YOLOX/blob/main/LICENSE. Код декларирует Apache-2.0, поддерживает ONNX export. Это **не** доказывает лицензию любого стороннего обученного checkpoint.
2. **Исследовательский источник для bbox** — https://universe.roboflow.com/ahmedelmogtaba-ali/honey_bees_dataset : заявлены CC BY 4.0 и 204 исходных изображения (в разных версиях число увеличено аугментациями). Нужно отдельно скачать/сверить условия конкретной версии и установить авторство всех изображений, наличие корректных меток и пригодность к ракурсу летка.
3. **Кандидат с пчёлами и пыльцой** — https://universe.roboflow.com/honey-bee-project/honey-bee-project : заявлена CC BY 4.0 и классы Apis mellifera / Apis mellifera Pollen. Лицензия опубликованного сервиса/модели не тождественна правам на экспорт checkpoint.
4. **Возможная бесплатная среда обучения** — https://www.kaggle.com/docs/notebooks и https://www.kaggle.com/docs/efficient-gpu-usage : Kaggle документирует ограниченный бесплатный GPU, зависящий от доступности/квот. Платные тарифы, привязка оплаты и автоматические списания запрещены. Использовать только **лицензированные общедоступные тренировочные данные**, никогда пользовательские исходные видео пасеки без отдельного разрешения.

## План проверки перед любым обучением
- Независимо разрешить лицензию кода, конкретного base checkpoint или режим **training from scratch**, исходных данных и аннотаций; зафиксировать версии и SHA-256 исходников. Нельзя приписывать Apache-2.0 новым весам лишь потому, что архитектура YOLOX Apache.
- Проверить распределение по исходным роликам/ульям/датам; не включать близкие кадры одной съёмки одновременно в train и test. Использовать isolated `PasekaVideoDatasetIsolation` только как первое автоматическое ограничение: его манифест — декларативный.
- Сформировать небольшой внешний тестовый датасет, **не содержащий приватные видео пользователя**, с реальными bbox пчёл на летке, включая тени, перекрытия, низкую активность и ложные объекты.
- Экспортировать модель в ONNX с воспроизводимыми настройками, фиксировать SHA-256 весов и размер; отдельно изучить наличие неподдерживаемых ONNX operators для браузерного WASM.
- После проверки прав и качества на ПК — offline Android CPU/WASM benchmark на физическом устройстве и измерения потребления памяти.
- Только после успешной модели — локальный source-bound inference и durable ledger. Никаких автообъявлений `completed` по синтетическим данным. Удаление видео отдельно блокируется до доказанного all-copy cleanup.

## Исключённый shortcut
Датасет https://pmc.ncbi.nlm.nih.gov/articles/PMC10831503/ содержит 7200 кадров с восьми ульев и разметку направления, но публикация помечена CC BY-NC-ND. **Не использовать его автоматически для обучения/модификации/распространения в приложении** без отдельной проверки прав. Рассматривать только как потенциальный источник для юридически допустимого исследования.

## Ограничения
Сегодня отсутствуют: реальный утверждённый checkpoint, воспроизводимый training run, ONNX export, Android inference, независимые метрики точности и tracking, all-copy cleanup. Этот документ не даёт ни технического, ни юридического разрешения на внедрение.
