### Заблокированный экран — F2 исследование, NOT_IMPLEMENTED

Android 14+ требует microphone foreground service type, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MICROPHONE, RECORD_AUDIO, запуск при видимой Activity, исключения нельзя использовать для скрытой активации. Источники: https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start и https://developer.android.com/about/versions/14/changes/fgs-types-required ; Android 15/14 запрещает запуск microphone FGS из BOOT_COMPLETED (https://developer.android.com/about/versions/15/changes/foreground-service-types). Локальный TTS: https://developer.android.com/reference/android/speech/tts/Voice и https://developer.android.com/reference/android/speech/tts/TextToSpeech.Engine . Выбран возможный следующий архитектурный путь: отдельный явно включаемый microphone FGS, постоянное уведомление с Stop, bounded session, stop on mic revocation/task removal/error, no boot/restart, не использовать archive JobScheduler как микрофонный сервис; уведомление не должно содержать заметки. При locked screen не выполнять операции/сохранение; только временный черновик, review после unlock. Пока нет физического подтверждения базового Vosk/TTS и lifecycle, FGS не активировать. Проверка: OnePlus/Android API 35+, screen lock/unlock, headset, call, privacy toggle, notification Stop, battery/OxygenOS, no wake/record on cold start. Нет гарантии работы с выключенным экраном. Ни одна запись/физическая операция production не меняется.
