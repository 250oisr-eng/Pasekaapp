# B01 · Единый локальный тест архива и медиа (контракт F0–F2)

**Дата:** 26.11.2026. **Статус:** LIMITED_SAFE_DRAFT. **Источник:** запрос пользователя «собери единый тест и закрой все вопросы им» и P0/B01 из [реестра](РЕЕСТР-БЛОКЕРОВ.md). Синтетический тест не заменяет физические доказательства.

## F0. Повторное использование вместо дублирования

В main уже есть `scripts/verify-exported-archive.mjs` для bounded read, v3/full store SHA и структурной проверки. В [Draft #541](https://github.com/250oisr-eng/Pasekaapp/pull/541) есть `scripts/audit-local-media-copy.mjs` для потокового побайтового сравнения ранее скопированных файлов, без доступа к телефону. В [Draft #537](https://github.com/250oisr-eng/Pasekaapp/pull/537) доказан физический `DIAGNOSTIC_SIGNER_MISMATCH`; APK нельзя обновлять, force-stop/relaunch тесты не повторять. Новый шаг — объединить **только** локальные безопасные проверки, не создавать дубликаты P0 runner.

## F1. Контракт

Одно локальное действие: запустить `node scripts/run-unified-recovery-audit.mjs` с четырьмя optional аргументами (полный внешний JSON, два внешних каталога медиа, ожидаемое число файлов). Скрипт **читает** существующие данные и выводит один обезличенный JSON. Не создаёт резервную копию, не пишет в исходники, не подключается к ADB/OnePlus, не запускает APK, не получает доступ к живой `paseka-v1`, не очищает ничего.

Проверки и инварианты:

| Ворота | Подтверждается | Не подтверждается |
|---|---|---|
| B01 Archive | Формат `paseka-idb-full-v1`, все stores, payload SHA/counts, содержимое Blob в уже экспортированном файле | Полнота выгрузки с реального устройства и всех origins |
| B01 Isolated memory replay | Атомарное восстановление в **новую временную fake-indexeddb**, close/reopen и повторный hash | Физическое восстановление на устройстве, срок хранения, durable disk, power loss |
| B01 External media | Совпадение двух **перечисленных** локальных каталогов по файлам/байтам | Все копии Gallery/MediaStore, независимость двух физических носителей, телефоны/права |
| B04/B05 | Не тестируется, в отчёте `NOT_VERIFIED_IN_THIS_TEST` | Совместимый production signer, наличие постоянного private key |
| B06/B10 | Явное `FROZEN`; delete=false | Лицензия весов и реальная детекция пчёл |

**Опасные действия:** любые live restore/install/uninstall, очистка IndexedDB, автоматическое удаление видео, запись в оригиналы, доступ к production запрещены; не реализованы.

## F2. Ресурсы и STOP

Доступен бесплатный Node.js + fake-indexeddb и существующие read-only модули. Реальный внешний архив, исчерпывающий inventory всех источников OnePlus, независимый empty physical target и доказательство восстановленного видео в этом контексте **отсутствуют**. Поэтому F2 = LIMITED_SAFE_DRAFT. Любой результат этого скрипта заканчивается открытыми физическими воротами и кодом процесса **2** (если все локальные проверки прошли или ещё нет всех входов) либо **1** (локальный отказ). Кода выхода 0 до отдельного физического доказательства **нет**. Запреты удаления и обновления APK не ослабляются.

## Следующий проверяемый результат

CI должен подтвердить один корректный синтетический экспорт (включая неизвестный legacy store и Blob), независимый close/reopen, byte SHA сравнение, негативные исходы, sanitize отчёта и no-op для пользовательской файловой системы. Реальный B01 остаётся BLOCKED до внешних оригиналов и независимого восстановления. Отдельное разрешение нужно только для merge/production/release/delete.
