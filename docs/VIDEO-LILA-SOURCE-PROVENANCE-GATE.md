# Контроль происхождения кадров LILA перед обучением и оценкой

Дата: 2026-11-20. Статус: **блокирующая проверка; исходная принадлежность кадров пока не подтверждена**.

## Проверенные свидетельства

1. Официальная карточка `Boxes on Bees and Pollen` описывает проект BeeLivingSensor и 4993 изображения с Pascal VOC XML, публикует ссылку на ZIP и указывает CDLA-Permissive: https://lila.science/datasets/boxes-on-bees-and-pollen .
2. Исследовательский GitHub CI PR #274 установил состав ZIP directory: 4993 XML + 3752 JPEG + 1241 PNG. Проверены только пять реальных XML/image пар через ограниченные HTTP Range; не весь архив.
3. PR #275 создал локальный PNG/JPEG-aware конвертер в единый `unassigned` COCO; exact HEAD `5f12439cd21bc9d8c98b2b2c06c76e8ffdbfb3b9`: Android workflow #44738340971 completed/success, isolated #44738340889 skipped. Это проверка конвертера и сборки, **не обучения/распознавания на телефоне**.
4. Упоминание BeeLivingSensor на карточке не даёт проверяемого соответствия каждого изображения его исходному видео, улью, дате и сессии. Имя `Chueried_HempBox_1` само по себе не подтверждает такую связь.

## Требуемые свидетельства для независимого split

| Проверка | Минимальное доказательство | Текущий статус |
|---|---|---|
| Права исходных данных | Лицензионные условия и атрибуция конкретной версии набора, выполненные обязательства публикации | Заявленная лицензия на карточке; отдельный аудит распространения не завершён |
| Принадлежность изображения | Таблица image SHA256 → документально подтверждённый source recording/session ID | **Неизвестно** |
| Группировка | Одна исходная видеосессия целиком в одном partition; при наличии подтверждённой группы улья/дня не допускать утечки между partition | **Не проверено** |
| Репрезентативность | Явно классифицированные полные кадры летка и crop/pollen/negative изображения; независимый ручной аудит меток | **Не проверено** |
| Обучение | Воспроизводимый train/validation/test manifest с источниками и хешами, лицензированные веса/код и реальные метрики по holdout | **Не выполнялось** |
| Android | Подписанный provenance модели, успешный offline inference на физическом телефоне, измерения скорости/точности | **Не выполнялось** |
| Удаление видео | Достоверно завершённое распознавание + подтверждение охвата всех локальных копий, атомарный безопасный cleanup и отказ при ошибках | **Запрещено до проверки** |

## Правило решения

Если для изображения отсутствует независимое подтверждение записи/сессии, оно сохраняет `split=unassigned`. Нельзя строить train/test на основе случайного деления файлов, имени, сортировки ZIP, формата изображения или предположения, что crop является независимой съёмкой. Не подменять задачу детекции пчёл задачей подсчёта направленных пересечений летка: для второй требуется отдельная разметка траекторий/пересечений.

Следующий безопасный этап — получить **первичные метаданные BeeLivingSensor** с проверяемым сопоставлением source-recording и image SHA или документированно признать эти сведения отсутствующими. Лишь после этого разрабатывать split, train/validate/test и лицензированный offline detector. Если происхождение не подтверждается, допустимо оставить LILA только unassigned исследовательским набором и искать другой источник с подтверждёнными видеосессиями.

Никакой исходный файл пользователя не был открыт, перемещён или удалён. `modelApproved=false`, `recognitionSucceeded=false`, `cleanupAuthorized=false`. Документ сам по себе не выдаёт разрешений на обучение, эксплуатацию либо удаление.
