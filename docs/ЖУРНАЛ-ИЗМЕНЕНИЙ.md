## Подтверждение пользователя — 2026-11-17: постоянный комплект подкрышников и крышек

Пользователь подтвердил: во всех рабочих состояниях секционного улья — один ряд, два ряда, два ряда с медовыми корпусами — используются **ровно три подкрышника и три крышки**. Временные подкрышники и временные крышки не применяются; комплект не снимается из учёта при переходе к промежуточному состоянию одного ряда.

Происхождение и границы:
- DOCX на стр. 1 перечисляет комплект из трёх подкрышников и трёх крышек.
- DOCX P10–P12 описывает установку второго ряда как действие, которое можно отложить на несколько дней, а затем установку трёх подкрышников и крышек. Это описание само по себе не устанавливает комплектность промежуточного состояния одного ряда.
- Уточнение о неизменном количестве в каждом рабочем состоянии — отдельное решение пользователя от 2026-11-17; не приписывать его DOCX.
- В физической модели необходимо сохранять три отдельные записи каждого типа (topRiser и cover) и проверять их наличие в каждом из трёх стеков. Точное место крепления/размещения при установке медовых корпусов должно соответствовать фактической конструкции и не выводиться из одного только количества.

Следствие для OP-04: прежний блокер о неизвестности временного укрытия закрыт пользовательским подтверждением — временный комплект не нужен. Остаётся задача моделирования промежуточного состояния после первого ряда и перехода ко второму ряду; текущая реализация coordinator завершает только итоговую конфигурацию с двумя гнездовыми корпусами на секцию. До реализации staged state нельзя считать эту часть OP-04 полностью поддержанной.

## Решение пользователя — учёт пустых корпусов и комплектности рамок (2026-11-17)

Пользователь уточнил два состояния из DOCX:
- P57: временный корпус без рамок используется только для стряхивания пчёл с рамок в общую семью, после чего корпус убирается. Эта вспомогательная операция и временное использование корпуса **не учитываются в приложении**: не создают установленный корпус, запись инвентарного перемещения или технологическое событие.
- P77: «пустой корпус» означает **незаселённый корпус с рамками**. Это реальный установленный корпус, он учитывается в физической раскладке, инвентаре и истории оборудования.

Следствие: правило полной комплектности не имеет исключения для установленных корпусов. Каждый учитываемый установленный корпус должен содержать ровно число рамок, соответствующее его вместимости. «Пустой» по заселённости корпус не означает отсутствие рамок. Временный корпус P57 находится вне модели учёта приложения.
