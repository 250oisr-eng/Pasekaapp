# Паспорт состояния проекта «Пасека»

Дата фиксации: 2026-11-14

## Назначение
Мобильное offline-first приложение для ведения пасеки. PWA работает в браузере; Android-оболочка построена на Capacitor.

## Подтверждённая основа
- Основные данные хранятся локально в IndexedDB.
- Основные разделы и предметная модель описаны в корневом README.
- ИИ-функции зависят от сети, Neon Auth и Cloudflare Worker; локальные функции не должны зависеть от доступности ИИ.
- Полная синхронизация между устройствами в README обозначена как не реализованная.
- Регрессионный набор запускается через `npm test`.

## Незавершённые изменения
- PR #14: полный архив `.paseka` и безопасное восстановление.
- PR #15: локальные вращаемые снимки IndexedDB; зависит от ветки PR #14.
- Этот пакет документации: ветка основана на PR #15 и должна интегрироваться после PR #15.
- Cloud sync consent gate не считать реализованным, пока не появятся код и тесты, подтверждающие default-off и явное согласие владельца.

Все перечисленные PR остаются черновыми до отдельной проверки. Не сливать зависимые ветки в обход их базовых PR.

## Правила сохранности
1. Не работать напрямую в `main`.
2. Не удалять старые форматы экспорта, миграции и механизмы восстановления без отдельного плана совместимости.
3. Не считать локальные снимки внешней резервной копией: они находятся на том же устройстве.
4. Не считать успешный CI доказательством физической проверки на Android.
5. Не помещать секреты, токены, пароли, JWT и приватные ключи в репозиторий.
