# Реестр сервисов и отказоустойчивость

Реестр описывает назначение компонентов, а не гарантирует доступность или бесплатность их тарифов. Перед использованием проверяйте текущие условия и лимиты.

| Компонент | Назначение | Что делать при недоступности |
|---|---|---|
| GitHub | Git, PR, CI, артефакты | Использовать локальный Git mirror/bundle; тесты запускать локально |
| GitHub Actions | Проверки и Android debug build | Запускать npm test локально; сборку отложить при отсутствии SDK |
| Neon Auth | Авторизация серверных ИИ-функций | Отключить серверные функции; локальный журнал продолжает работать |
| Cloudflare Worker / Workers AI | ИИ-запросы | Показывать недоступность; не блокировать локальные операции |
| Lovable | Вспомогательная разработка UI | Редактировать код напрямую в Git |
| TinyFish | Поиск и браузерные проверки | Использовать ручную проверку/альтернативный поиск |
| ChatGPT и другие ИИ | Анализ, проектирование, код | Передать работу по AI_HANDOVER.md |

## Финансовое правило
Никаких платных операций, подписок, пополнений, автоматического продления и расходования платных кредитов без отдельного разрешения владельца.

## Секреты
Секреты должны храниться только в менеджере секретов соответствующего сервиса. В этом файле не указывать имена приватных переменных со значениями, токены, account ID или URL, содержащие ключи.
