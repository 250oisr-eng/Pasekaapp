# Сборка и проверка

## Требования
Используйте версии Node.js и Java, указанные в workflow GitHub Actions и lock-файле репозитория. Не обновляйте инструменты только ради сборки без отдельной задачи.

## Установка
```bash
npm ci
```

## Регрессионные тесты
```bash
npm test
```

## Android
Debug APK собирается workflow **Build Android APK** в GitHub Actions. Успешная сборка не означает, что APK проверен на физическом устройстве.

## Если GitHub Actions недоступен
- Не удаляйте и не пересоздавайте workflow.
- Сохраните локальный вывод команд и версию Node/Java.
- Запустите `npm ci` и `npm test` локально, если среда доступна.
- Android-сборку выполняйте только при наличии Android SDK/Gradle и требуемых секретов; не заменяйте их случайными значениями.

## Воспроизводимость
- Использовать `npm ci`, а не `npm install`, в CI.
- Не удалять `package-lock.json`.
- Не обновлять зависимости без проверки полного набора тестов и аудита изменений.
