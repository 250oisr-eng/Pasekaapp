# Архитектура и границы зависимостей

## Клиент
- PWA + Android-оболочка Capacitor.
- Локальные данные — IndexedDB.
- Service Worker обеспечивает offline cache.
- Основные операции учёта должны работать без сетевого соединения.

## Внешние компоненты
- Neon Auth — авторизация для серверных функций.
- Cloudflare Worker — серверный посредник для ИИ.
- Cloudflare Workers AI — модель для ИИ-функций.
- GitHub Actions — автоматические проверки и Android debug-сборка.

## Правило деградации
Недоступность внешнего компонента не должна блокировать открытие локального журнала, просмотр ульев, осмотры и локальные расчёты. ИИ и другие сетевые возможности могут быть недоступны, но должны отказывать безопасно и явно.

## Данные
- Не отправлять данные пасеки во внешние сервисы без понятного действия пользователя и информирования о передаче.
- Облачная синхронизация между устройствами не считается доступной функцией, пока она отдельно не реализована и не проверена.
- Резервный архив должен включать оригиналы видео летка, а не только ссылки или миниатюры.

## Изменение архитектуры
Любое добавление облачного сервиса должно сопровождаться:
1. описанием данных, которые покидают устройство;
2. явным переключателем/согласием пользователя, если включается синхронизация;
3. безопасным поведением при истечении токена, лимита или отключении сервиса;
4. локальным путём продолжения работы;
5. тестами отказа сети и сервиса.
