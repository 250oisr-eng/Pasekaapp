# Контроль источников для видеоаналитики: только Apis mellifera

Дата: 2026-11-21. Пользователь подтвердил обязательное правило: **только Apis mellifera**, в том числе явно обозначенные подвиды Apis mellifera. Источники другого рода/вида не должны участвовать в обучении и измерении качества модели «Пасека».

## Иерархия подтверждений

1. **Биологический вид:** должен быть указан конкретно научным названием в записи авторов/издателя. Бытовое «bee» или «honey bee» без подтверждения вида в наборе недостаточно. Отдельная фотография не является доказательством видовой принадлежности на уровне каждого объекта; статус основан на заявлении издателя.
2. **Лицензия конкретного набора:** подтверждена в авторитетном источнике; лицензия статьи, кода или модели не означает лицензию изображений. Требуется сохранение атрибуции и ссылки на источник. Ни одной платной зависимости.
3. **Оригинальные данные:** должны быть получены из официального источника и проверены по размеру и контрольной сумме. Заявления на странице не являются проверкой исходных бинарных файлов.
4. **Независимый train/validation/test:** исключить побайтовое совпадение изображений и пересечение исходных съёмочных сессий. Если source session IDs/физические видеосессии не установлены, статус независимости неизвестен; файл с названием `test` не доказывает её.
5. **Технологическое назначение:** detection, pollen instance segmentation, tracking, U-turn, физические in/out — разные GT-задачи. Нельзя объявлять общий подсчёт входов и выходов из статических JPEG.

## Исключённые/заблокированные наборы

- **Monash Australian Native Bee Dataset** DOI 10.26180/32315067.v1: издатель указывает `Tetragonula carbonaria`, это **не Apis mellifera**. Предыдущий код источникового аудита в Draft #319 сохраняется только как документирование и диагностика неисправности исходной разметки. **Никакого использования Monash для обучения/валидации модели «Пасека»**. Побайтовой аудит нашёл, что 3277/3277 detection JPG повторяются в tracking ZIP, отдельная причина запрета наивного split.
- **Boxes on Bees and Pollen** https://lila.science/datasets/boxes-on-bees-and-pollen: издатель заявляет «honey bees» и CDLA-Permissive, но на просмотренной карточке **не подтверждено точное латинское название Apis mellifera**. До дополнительного авторитетного подтверждения видовой принадлежности — исключён.
- VnBeeTracking — лицензия только для академического некоммерческого исследования не соответствует проверенному разрешению на свободное использование в целевом приложении; BEE24 и другие источники без прямого доказательства вида/прав — исключены.
- Авторские 1194 compound events Nieves-Rivera — пока без проверенного codebook, manifest, лицензии исходников и видео. Эти события нельзя напрямую включить в независимый бенчмарк.

## Контроль в коде

- `tools/audit_apis_mellifera_source_gate.py`: точный allowlist на конкретный DOI v1, таксон и лицензию; контроль `candidate_status` отвергает подмену известной версии, лицензии или вида. **«Metadata eligible» означает только приоритет при проверке оригиналов**, не разрешение тренировать.
- `validate_synthetic_session_split` принимает *только изолированные синтетические* записи с полями `source_id`, `observation_id`, `frame_sha256`, `capture_session_sha256`, `split`. Отвергает дубликаты изображений между/внутри выборок, один session SHA в разных выборках, неизвестные/неполные SHA-256 и смешение источников. **Не может доказать, что переданный session SHA действительно рассчитан по реальному оригинальному видео**.
- `tests/test_apis_mellifera_source_gate.py`: регрессии на исключение Monash, неизвестных видов/лицензий, поддельного таксона, data leakage, отсутствие сессий, неполный split и недопуск к обучению/удалению.
- Бесплатный CI `.github/workflows/test-apis-mellifera-source-gate.yml` проверяет только эти ограничения; не скачивает и не публикует изображения.

## Следующий самостоятельный этап

Получить оригинальные, лицензионно подходящие binary assets **BEEHIVE v1** и **pollen-beedata v1**; проверить размеры и SHA-256, подлинную разметку, реальное распределение по исходным съёмкам и перекрытие source SHA между выборками. Не включать training, пока original image bytes и независимость сессий не доказаны. Для финальной проверки видеосчётчика искать именно Apis mellifera видеособытия с верифицируемыми входами, выходами и разворотами и калиброванной физической границей летка.

Установленное пользователем правило о жизни оригинала на телефоне сохраняется: после **реально подтверждённого распознавания** удалить через отдельно проверенную безопасную runtime-процедуру. Исследовательский скрипт не вправе сам инициировать очистку.
