# Аудит доступных моделей и датасетов для видео летка (20.11.2026)

Статус: исследование и выбор кандидатов для **следующего реального inference**, не внедрение модели. Проверка проведена по публичным страницам проектов на указанную дату; факт наличия GitHub-проекта не подтверждает юридическую допустимость интеграции, наличие весов или достаточную точность.

## Технические и бюджетные ограничения
- Критерий №1: работа на Android/Chromium, желательно полностью offline, без выгрузки личного видео/кадров и без оплаты.
- Runtime-кандидат: ONNX Runtime Web (официально MIT и WASM browser inference), https://github.com/microsoft/onnxruntime/blob/main/LICENSE и https://onnxruntime.ai/docs/get-started/with-javascript/web.html . Лицензия runtime не заменяет права на модель/веса/датасет.
- Нужны подтверждённые **honeybee** detection/tracking на летке с направлением `in/out`, а не просто классификация общего изображения. Признаки пыльцы, трутней, ос и клинические выводы не считать доказанными без соответствующих тестов и разметки.
- Любая бесплатная облачная квота, которая основана лишь на разовых welcome credits, запрещена политикой бесплатных средств проекта.

## Промежуточный вывод

**Подтверждённой бесплатной Android-совместимой модели для пчёл, ос, направления движения и пыльцы пока нет.** Более корректный порядок: сначала юридически чистые веса honeybee detector, затем независимый benchmark на видео пользователя разных условий (качество, фон, направление движения), затем tracking и only-observations draft. Нельзя считать `zero detections` успешным распознаванием без измеренной чувствительности модели. Нельзя классифицировать отсутствие матки, отравление или болезнь по одному видео летка.

До выполнения всех критериев остаются неактивными: `js/entrance-frame-preparation.js`, `js/video-model-evidence.js`, `js/video-observation-pipeline.js`. `js/video-recognition-ledger.js` не подключён к реальному inference. `canDeleteVideoOriginal()` и `deleteEntranceVideoBlob()` по-прежнему отказывают.

## Следующие технические проверки

1. Проверка лицензии runtime+конкретных model weights+dataset, веса фиксировать по SHA-256 и точной версии.
2. Браузерный CPU/WASM benchmark на Android устройства, ограничение RAM, timeouts, offline reload.
3. Датасет с реальными ошибками, precision/recall/tracking ID switches, направление `in/out` и различение нулевого результата от ошибки.
4. Устойчивое сохранение заверенного source-bound результата, отдельное подтверждение пчеловодом, а затем **отдельно** proof all-copy Android cleanup; до того видео не удалять.
