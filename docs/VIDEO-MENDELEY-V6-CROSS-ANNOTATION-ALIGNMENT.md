# Mendeley v6: покадровая независимая сверка detection YOLO с fan-tracking TXT

**Дата:** 2026-11-21. **Статус:** воспроизводимый исследовательский аудит реальных публичных данных, не обучение детектора и не разрешение на удаление видео.

## Причина исследования

Предшествующий инструмент `tools/compare_mendeley_v6_fan_frames.py` сопоставил 12 JPG одной опубликованной серии `20230711a` с 6000 кадрами видео `20230711a-fan.mp4` по полной яркости. У ряда JPG ближайшими оказывались одинаковые кадры 745 и 1956; общий фон почти одинаков и **не доказывает** соответствие отдельных пчёл, номера кадра или исходной видеосессии.

Теперь `tools/audit_mendeley_v6_cross_annotation_frame_alignment.py` выполняет следующую проверку только на оригинальных байтах:

1. По **издательскому** CSV `tests/fixtures/mendeley-v6-publisher-checksums.csv` определяет **ровно 12** JPEG с именем `20230711a*.jpg` и 12 одноимённых TXT (все записи `listed_v6`, размер и SHA-256 с версией 6, отдельный UUID каждого файла).
2. Загружает только эти исходные публичные JPEG/TXT и уже изученный оригинальный `20230711a-fan.mp4` с `tracks_20230711a-fan.txt`; **каждый** файл проверяет по издательскому размеру и SHA-256 до анализа. Непроверенные/подменённые файлы приводят к отказу.
3. Полностью декодирует каждый JPEG, не изменяя размер 1920×1080, читает независимые YOLO метки `class=0, cx,cy,w,h`. Если координаты выходят за границы кадра, файл отклоняется; не выполняется незаметной нормализации или обрезки.
4. Исходный MP4 декодируется целиком, выбираются **только по яркости**, без обращения к YOLO или tracking ID, три наиболее близких кадра к каждому JPG. Этап кандидатов переиспользует исходный `compare_series`.
5. Отдельно сравнивает YOLO рамки оригинального JPEG и GT рамки выбранных кадров tracking TXT при IoU≥0.5 (Hungarian one-to-one) и фиксирует количество совпадений, исходные количества рамок, индекс кадра с нуля, pixel-MAE и средний IoU **только сопоставленных** рамок.
6. Кандидаты **не пересортировываются** по GT совпадениям: иначе успешный «поиск» нужного кадра был бы подменён знанием правильного ответа.

Важное методологическое различие: близкая яркость всего кадра — **только кандидат**. Сопоставление YOLO и GT даёт дополнительное свидетельство о конкретных объектах **после** выбора кандидата, но не удостоверяет источник физических записей и не подтверждает, что кадры обучающего и контрольного наборов независимы.

## Предотвращение train/test leakage

`screen_training_group_overlap([...], test_group="_bee_20230711a")` автоматически отклоняет попытку считать допустимым обучение на `_bee_20230711a` при проверке на одноимённом `20230711a-fan.mp4`. Исключение этой группы уменьшает очевидный риск, **но не доказывает независимость других дат, ульев и видеозаписей** — функция всегда возвращает `trainingAuthorized=false`. Не превращать раздельные названия папок в проверенные физические сессии.

Свидетельства, необходимые для честного обучения и независимого детекторного теста: исходные идентификаторы записей, проверенные соответствия кадров записям и проверенная физическая независимость данных между train/validation/test. Даже хорошее совпадение разметки не подменяет эти источники происхождения.

## Воспроизведение

Из корня репозитория в изолированном бесплатном CI runner:

```sh
python -m unittest discover -s tests -p 'test_audit_mendeley_v6_cross_annotation_frame_alignment.py' -v
python tools/audit_mendeley_v6_cross_annotation_frame_alignment.py
```

Потребуются Pillow, NumPy, SciPy и FFmpeg; настоящий MP4 и JPG **не коммитятся** и не записываются в пользовательскую память. Временные исходные файлы удаляются по завершении `TemporaryDirectory`. Конечный отчёт JSON в stdout содержит только имена, криптографические контрольные суммы и ограниченные измерения.

**Ограничения:** `exactSourceFrameMappingVerified=false`, `sourceRecordingIdentityVerified=false`, `holdoutIndependentVerified=false`, `modelTrainingAuthorized=false`, `beeRecognitionSucceeded=false`, `videoCleanupAuthorized=false`. Ни одна технологическая операция пасеки и ни один исходный файл пользователя не изменяется.

**Источник:** Tomyslav Sledevic, *Labeled dataset for bee detection and direction estimation on beehive landing boards*, Mendeley Data v6, DOI 10.17632/8gb9r2yhfc.6, CC BY 4.0. Все опубликованные контрольные суммы сохраняются без изменения.
