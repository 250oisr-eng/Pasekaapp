## F0. Первичный технологический источник

Проверен загруженный пользователем оригинал «улей для каждого техпроцесс.docx», абзацы P72–P76.

1. **Обычное весеннее развитие без раннего медосбора (P72–P74):** после облёта не разделять семьи немедленно; дать двум отводкам развиваться и пользоваться теплом сильной семьи через сетчатые диафрагмы. «Около полутора месяцев» — ориентир, не разрешение по календарю. После фактического развития отделить отводки на свои днища и продолжать развитие; добавление последующих корпусов описано в процессе роста, а не как одинаковый немедленный шаг для каждого сценария.
2. **Подготовка к раннему медосбору (P74–P76):** после фактического развития отводков выполнить отделение на два дополнительных днища, снять диафрагмы, дать по одному дополнительному пустому гнездовому корпусу и вернуть подкрышники и крышки. Только для этого подтверждённого варианта прежняя 2+1+1 схема преобразуется в 2+2+2 с двумя новыми корпусами.

Нельзя переносить требование немедленной установки двух корпусов из раннего сценария на обычный. Нельзя считать прошедшие дни или приблизительный срок доказательством силы семей и выполненных физических действий.
