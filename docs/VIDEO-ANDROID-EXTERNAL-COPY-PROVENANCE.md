# Неизвестные внешние копии Android (2026-11-20)

Приложение использует HTML file input с `capture="environment"`. В разных браузерах и Android-camera приложениях это может открыть камеру, системный picker или Галерею. **File input не доказывает, что после выбора исходника отсутствует ещё одна копия в MediaStore/DCIM/Галерее.** IndexedDB хранит только выбранный Blob.

Поэтому для **новых** летковых видео в record добавлено `captureProvenance:{source:'file_input_or_external_camera',externalCopyState:'unknown',verifiedAt:null}`. Это дополнительное поле без изменения IndexedDB version; старые записи не мигрируются и отсутствие поля означает то же «неизвестно». Запись в `entrance_media` остаётся локальной и неизменной по идентичности, bytes и SHA.

После успешного локального сохранения UI предупреждает, что внешняя копия могла остаться в камере/Галерее, а приложение не может подтвердить её отсутствие или удалить её автоматически. Список также сообщает, что внешние копии не проверены. Кнопка удаления и direct delete API по-прежнему заблокированы.

Эта запись **не позволяет перечислить/удалить внешние Android MediaStore файлы** и не создает новых разрешений. Нельзя показывать пользователю утверждение «всё видео удалено» или автоматически чистить внешние файлы, пока не реализован отдельный проверяемый Android ownership/URI protocol и физический тест.

В перспективе допустим отдельный собственный in-app capture API, чьё фактическое поведение подтверждено физической Android проверкой. До этого даже видео после AI распознавания остаются protected. Данные старых видео, резервные копии и файлы Галереи не удаляются.
