B01: независимая проверка IndexedDB

Только для отдельного Android-эмулятора и пакета ru.paseka.journal.diagnostic.restore. Не устанавливайте на рабочий OnePlus. Данные приложения не изменяются; проверяются только наличие базы, схема и количество записей.

Наличие записей само по себе не подтверждает полное восстановление, содержимое видео или совместимость миграций.
