ПАСЕКА 2.0 — ОДИН ЗАПУСК НА ФИЗИЧЕСКОМ ONEPLUS 10 PRO
Версия теста: 2026-11-26. Исключительно синтетическая проверка.

СЕЙЧАС (когда нет ПК): НИЧЕГО ДЕЛАТЬ НЕ НУЖНО.

Позже на ПК:
1. Скачайте из GitHub Actions -> Draft PR теста -> workflow "OnePlus synthetic recovery kit" -> artifact "PASEKA-ONEPLUS-RECOVERY-ONECLICK" и распакуйте всю папку.
2. Подключите OnePlus 10 Pro по USB, включите USB debugging и подтвердите доверие компьютеру на телефоне. Android SDK platform-tools (adb) должен быть установлен на ПК; скрипт найдёт его по ANDROID_HOME / ANDROID_SDK_ROOT / %LOCALAPPDATA%\Android\Sdk.
3. Дважды нажмите ПРОВЕРИТЬ-ONEPLUS.cmd. Никаких команд вводить не нужно. При BLOCKED сохранить отчёт и не повторять до анализа причины.
4. При необходимости передайте только текст ONEPLUS-RECOVERY-RESULT.json (отчёт не содержит личных записей, серийного номера или содержимого телефона).

Что делает тест:
- Проверяет единственное авторизованное физическое USB-устройство OnePlus NE221x, Android API 35+.
- Проверяет SHA-256 диагностического APK и его привязку к отдельному пакету ru.paseka.journal.disasterproof2.
- Откажет, если этот диагностический пакет уже установлен, чтобы не затереть его прежние данные.
- Устанавливает только отдельное тестовое приложение, записывает в нём искусственные записи и Blob-видео.
- Проверяет архив, повреждённый архив, восстановление в отдельную пустую IndexedDB, побайтовую сверку и закрытие/повторное открытие.
- Принудительно останавливает и запускает ТОЛЬКО диагностическое приложение, проверяет восстановленную базу после перезапуска.
- Оставляет тестовую сборку и её синтетическую базу на телефоне для последующей диагностики. Не удаляет ничего автоматически.

Не делает: не устанавливает/не изменяет ru.paseka.journal, не читает реальный архив, не удаляет фото/видео, не чистит Android, не запускает production, не перезагружает телефон.
При отсутствии ADB/USB/авторизации или конфликте идентификатора завершает BLOCKED. Автоматически загрузок из интернета нет.
Реальная авария питания, реальная квота диска, миграция рабочих данных v1–v15 и восстановление реальных файлов данным тестом НЕ подтверждаются.
Этот тест пригоден только для отдельного приложения и при согласии пользователя на его установку.
