ПАСЕКА 2.0 — B01: проверка полного архива одним запуском
=========================================================

Этот пакет НЕ требует Android Studio, ADB, кабеля или установки APK.
В составе есть portable node.exe и проверенная локальная программа.
Он не соединяется с телефоном или интернетом, не удаляет и не меняет
содержимое источников, не восстанавливает живую базу.

1. В установленной «Пасеке» (на исходном телефоне) при доступности
   существующей функции экспорта: раздел резервного копирования →
   «P0 · Полный архив IndexedDB» →
   «Скачать полный архив текущей базы».
   Это действие создаёт новый локальный файл и не удаляет данные.
   Важно: если функция отсутствует/не работает, НЕ устанавливайте новую
   APK ради получения экспорта. Сохраняйте рабочую версию без изменений.
2. Перенесите СУЩЕСТВУЮЩИЙ экспортируемый JSON на ПК обычным
   безопасным способом. Он называется paseka-full-idb-YYYY-MM-DD.json.
   Личный файл не отправлять в чат, GitHub или облачные тесты.
3. Распакуйте этот пакет в отдельную папку. Оставьте ровно ОДИН
   полный экспорт .json в папке «Загрузки», на рабочем столе либо
   рядом с кнопкой запуска в папке пакета.
   Обычный Paseka JSON, TAR и LevelDB НЕ являются полным экспортом.
4. Дважды нажмите ПРОВЕРИТЬ-ПОЛНЫЙ-АРХИВ.cmd.
5. Передайте ТОЛЬКО B01-FULL-ARCHIVE-RESULT.json,
   который появится рядом с кнопкой запуска.

Ограничения:
- При нескольких кандидатах или отсутствии файла — BLOCKED.
  Не удаляйте/переименовывайте оригиналы для обхода защиты.
- Перед повторным запуском нужен новый отдельный экземпляр пакета,
  потому что существующий отчёт сохраняется без перезаписи.
- В памяти восстанавливаются все объявленные IndexedDB stores и
  проверяются бинарные данные Blob, затем база закрывается/открывается.
- Тест не доказывает реальный Android restore, наличие внешних
  видео Gallery/MediaStore, сохранение документа за пределами телефона
  либо возможность автоматического удаления оригиналов.
- Живые данные, оригинальные видео и резервные копии не изменять.
- Предел размера локального архива: 64 МиБ.
  Больший файл — BLOCKED без попытки восстановить, понадобится
  отдельно спроектированная потоковая проверка.
