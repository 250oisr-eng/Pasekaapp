PASEKA B01 — ЕДИНЫЙ ТЕСТ V11 ДЛЯ WINDOWS
=========================================
Один ZIP. Распаковать в НОВУЮ локальную папку, не в старую.
Дважды щёлкнуть START-ONEPLUS-UNIFIED.cmd.
НИЧЕГО переносить из прежних папок не надо.

ПО УМОЛЧАНИЮ — ТОЛЬКО ПК, БЕЗ USB И ЧТЕНИЯ ТЕЛЕФОНА
1. V11 ищет предыдущий public-only-v9.tar внутри результатов
   прежних V9/V9.1 (results\run-*\public-only-v9.tar) в папке
   запуска, Рабочем столе, Загрузках, Документах и стандартном OneDrive.
   Поиск ограничен по глубине/количеству папок; личные файлы не читает.
2. Автоматически выбирает НОВЕЙШИЙ найденный публичный TAR.
3. Если путь нестандартный, откроется окно выбора СУЩЕСТВУЮЩЕГО
   public-only-v9.tar: выберите файл на месте, НЕ копируйте его.
4. Если публичного TAR нигде нет и окно выбора закрыто, V11
   предлагает ввести USB: это отдельно разрешает безопасный телефонный
   preflight и проверку публичного TAR. Любой другой ввод завершает
   без доступа к телефону. Приватное чтение в V9.1 потребует
   ещё отдельного точного слова CAPTURE.
5. После проверки отправьте ТОЛЬКО ОДИН итоговый файл:
   unified-results\run-*\b01-unified-result.json

БЕЗОПАСНОСТЬ
- В автоматическом режиме телефон не используется, ADB не вызывается.
- Не удалять и не переписывать старые TAR/JSON, не трогать APK и IndexedDB.
- Содержимое TAR, его путь, фотографии и номера устройств не попадают
  в итоговый JSON. TAR нельзя загружать в чат, GitHub, облако или CI.
- Локальная форензика принимает ТОЛЬКО публичный файл с ожидаемым именем
  в старой структуре results\run-*; не принимает приватный архив.
- Даже если TAR структурно корректен, это НЕ полная копия и НЕ
  независимое восстановление. B01 BLOCKED до отдельного доказательства.
- Если USB-кандидат запущен вручную: пользоваться только официальным
  ADB 1.0.41+ с shell_v2, телефон NE2213, приложение закрыто.
  Ни установки, ни force-stop, ни удаления оригиналов не выполнять.
- Удобство не снижает ограничений безопасности. Без исходного файла
  нет подтверждения успеха; скрипт указывает NO_PREVIOUS_PUBLIC_TAR_FOUND.

ТЕХНИЧЕСКАЯ СХЕМА
Единая команда запускает RUN-ONEPLUS-UNIFIED-V11.ps1, который локально
вызывает вложенный read-only B01-PUBLIC-TAR-FORENSIC-V10.ps1.
При явном выборе USB вызывает вложенный B01-ONEPLUS-SAFE-V9.ps1
(V9.1) и затем локально диагностирует публичный результат.
Промежуточные файлы из разных версий не нужно объединять вручную.
